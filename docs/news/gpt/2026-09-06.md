### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> GPT-6 Astra Operating Robot Arms
OpenAI's GPT-6 Astra demonstrated superior robot arm control compared to Claude models on manipulation tasks, achieving a 95% success rate on a pick-and-place bowl task while using significantly fewer output tokens and costing less per run than competing models.

<ul class="takeaways">
<li>GPT-6 Astra: 95% success rate (19/20) on bowl task, 2.5 min average, $0.94 per run</li>
<li>Claude Fable 5.1: 40% success rate (8/20) on bowl task, 6.8 min average, $2.12 per run</li>
<li>Claude Fable 5: 5% success rate (1/20) on bowl task, 8.2 min average, $2.69 per run</li>
<li>Astra used 2.1k output tokens for bowl task vs. higher token use by Fable models</li>
<li>Puzzle task success rates: Astra 10% (2/20), Fable 5.1 10% (2/20), Fable 5 0% (0/20)</li>
<li>Testing on September 4, 2026: 20 trials per model per task</li>
</ul>
