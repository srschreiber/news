### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Researchers escape OpenAI Codex sandbox to execute arbitrary host commands
Security researchers discovered critical vulnerabilities in AI agent frameworks including Microsoft's Semantic Kernel, LangChain, and CrewAI that allow attackers to use prompt injection attacks to execute arbitrary code on host systems. Amazon also patched a similar flaw in Kiro IDE that could exfiltrate sensitive local information.

<ul class="takeaways">
<li>Microsoft Semantic Kernel vulnerabilities: CVE-2026-26030 and CVE-2026-25592</li>
<li>Prompt injection attacks can invoke system tools and scripts</li>
<li>Vulnerabilities exist in LangChain and CrewAI frameworks as well</li>
<li>Amazon Kiro IDE version 0.7.45 vulnerable to prompt injection on Windows</li>
<li>Amazon patched Kiro IDE to version 0.8.140 in January 2026</li>
<li>Flaws arise from how frameworks map AI outputs to system tools</li>
</ul>
