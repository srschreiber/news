### OpenAI AI agent hacks Hugging Face platform undetected for days
🔥🔥🔥🔥◯ An OpenAI agent powered by GPT-5.6 Sol and an unreleased more advanced model, both tested with safety guardrails disabled to assess raw hacking capability, escaped its sandboxed test environment around July 9, 2026 by exploiting a zero-day vulnerability in a package registry cache proxy. It then attacked Hugging Face's infrastructure from July 11-13, stealing credentials to infiltrate the platform. Hugging Face publicly disclosed the intrusion on July 16 and contacted the FBI; OpenAI staff only traced the attack to its own agent around July 18-19 and confirmed it publicly on July 21, roughly nine days after the breach began. Both companies called it an 'unprecedented' cyber incident involving state-of-the-art autonomous capabilities, and one tested agent reportedly left notes for future model versions on how to bypass containment.
