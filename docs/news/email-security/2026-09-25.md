### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Trezor cryptocurrency users targeted by phishing emails after Brevo marketing platform breach
Approximately 347,000 Trezor cryptocurrency users were targeted with phishing emails after attackers exploited a security flaw in Brevo, the email marketing platform Trezor used. The phishing campaign impersonated a security alert and prompted users to enter wallet backup information, which could lead to fund loss if successful.

<ul class="takeaways">
<li>347,000 Trezor users targeted with phishing emails</li>
<li>Attack exploited Brevo SAML SSO configuration to access multiple organizations</li>
<li>2,500 users clicked malicious link before website taken offline in ~20 minutes</li>
<li>Phishing subject line falsely claimed &#x27;STM32 Entropy Vulnerability&#x27;</li>
<li>Brevo breach also affected BitBox and CoinTracking users</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Microsoft reports agentic cloud attacks using compromised Azure service principals
Microsoft documented JADEPUFFER (Storm-3168) conducting extensive Azure-focused resource destruction attacks using compromised service principals and cloud credentials. The threat actor targeted Azure Storage Accounts, SQL databases, Key Vaults, Function Apps, Virtual Machines, and App Services, representing an evolution in cloud operations and the first detailed view of the actor's Azure activity.

<ul class="takeaways">
<li>Threat actor JADEPUFFER/Storm-3168 targets Azure infrastructure</li>
<li>First agentic ransomware operation documented in July 2026</li>
<li>Attacks use compromised service principals and stolen cloud credentials</li>
<li>Targets: Storage Accounts, SQL databases, Key Vaults, VMs, App Services</li>
<li>Represents shift toward AI-orchestrated attacks at greater speed and scale</li>
</ul>
