### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Power BI phishing campaign deploys rogue ScreenConnect clients
Attackers are phishing with emails impersonating Microsoft Power BI, directing victims to fake forms that download malicious ScreenConnect remote access clients. Campaigns exploit public Power BI dashboards on the trusted app.powerbi.com domain to bypass email filtering, fingerprint systems, and deploy two ScreenConnect clients for persistence and evasion.

<ul class="takeaways">
<li>Campaign started Sept 10, 2026</li>
<li>Exploits trusted Microsoft domain to bypass email filters</li>
<li>Malware fingerprints OS, browser, screen size, automation, cloud-provider data</li>
<li>ScreenConnect clients from attacker-controlled domains</li>
<li>Huntress found 22+ affected endpoints across incidents; initially affected handful</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> New Ghost Phishing Wave Breaks Traditional Email Security Defenses
The EvilTokens-attributed campaign uses "ghost phishing" to bypass email security by encrypting malicious HTML with AES-GCM, rendering in victim browsers only after decryption. Attacks exploit Microsoft Device Code phishing and target 194 countries across technology, finance, manufacturing, and security sectors.

<ul class="takeaways">
<li>&#x27;Ghost phishing&#x27; technique encrypts malicious HTML with AES-GCM, defeating static URL checks</li>
<li>Bypasses network-level security controls until decryption in victim browser</li>
<li>Microsoft Device Code phishing tricks users into authorizing account access without password theft</li>
<li>SOCRadar verified 86,644+ compromised devices across 194 countries</li>
<li>Phishing exposure rates: consulting 75.6%, financial services 72.8%, manufacturing 71.9%, technology 67.9%, banking 66.7%, MSSPs 66.1%</li>
</ul>
