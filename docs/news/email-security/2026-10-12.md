### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Microsoft Power BI phishing campaign deploys ScreenConnect RMMs for persistent access
Attackers used phishing emails targeting Microsoft Power BI to deploy rogue ScreenConnect remote management tools for sustained system access.

<ul class="takeaways">
<li>Campaign started Sept 10, 2026</li>
<li>Exploits trusted Microsoft domain to bypass email filters</li>
<li>Malware fingerprints OS, browser, screen size, automation, cloud-provider data</li>
<li>ScreenConnect clients from attacker-controlled domains</li>
<li>Huntress found 22+ affected endpoints across incidents; initially affected handful</li>
</ul>

### <span class="imp imp-mid" title="Importance 6/10" aria-label="Importance 6 of 10">6</span> Over 31,000 scam emails exploit Microsoft authentication system in seven weeks
Security researchers detected more than 31,000 phishing emails abusing Microsoft's authentication systems over a seven-week period.

<ul class="takeaways">
<li>Over 31,000 fraudulent emails identified August 1–September 18, 2026</li>
<li>Two attack vectors: fraudsters registered Microsoft apps with malicious redirect URIs; attackers used Entra admin center to create bogus users and set victims&#x27; emails as backup mailboxes</li>
<li>Scams mimicked official Microsoft communications urging credential updates or electronic document signatures</li>
<li>Attacks harder to detect because fraudulent links sent through official Microsoft services rather than spoofed addresses</li>
<li>Attackers purchased cheapest Microsoft licenses or used trial periods to access Entra admin center</li>
</ul>
