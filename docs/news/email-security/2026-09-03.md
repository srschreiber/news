### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Threat actors impersonate IT support via Microsoft Teams to breach enterprises
Microsoft Threat Intelligence documented a campaign where attackers impersonate IT support via Teams external collaboration to socially engineer remote access, then deploy obfuscated Node.js implants enabling persistent command execution and lateral movement. The campaign uses legitimate tools to blend into normal operations and precedes data theft, ransomware, and extortion.

<ul class="takeaways">
<li>Threat actors impersonate IT/helpdesk via Teams external collaboration</li>
<li>Deliver malicious MSI with portable Node.js runtime and obfuscated JavaScript implant</li>
<li>Implant enables C2, screenshots, PowerShell execution, WinRM lateral movement</li>
<li>Activity patterns suggest precursors to ransomware, extortion, data theft</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Unicode smuggling technique adapted for email phishing evasion
Invisible Unicode tag characters (U+E0000 to U+E007F) previously used for AI prompt injection are now being repurposed to evade email filters in phishing attacks. A high-volume phishing campaign beginning February 9, 2026, uses this ASCII smuggling technique to split financial lure words and bypass email filters.

<ul class="takeaways">
<li>High-volume phishing campaign started February 9, 2026</li>
<li>Uses invisible Unicode tag characters (U+E0000–U+E007F) to split keywords like &#x27;funding&#x27;</li>
<li>Technique adapted from AI prompt injection research</li>
<li>Microsoft Defender detections elevated for approximately three months</li>
<li>Most flagged messages caught by layered protections rather than single Unicode signals</li>
</ul>
