### ChainDrop supply chain attack compromises over 400 npm packages
<span class="imp imp-4" title="Importance 4/5" aria-label="Importance 4 of 5"><i class="on"></i><i class="on"></i><i class="on"></i><i class="on"></i><i></i></span> A self-propagating worm dubbed ChainDrop infected over 400 npm packages by hijacking a compromised maintainer account, then automatically re-poisoned hundreds more packages to steal developer credentials across major cloud and CI tools.

<ul class="takeaways">
<li>2,200+ malicious versions across 440 npm packages published</li>
<li>Started from 11 malware carriers in keyv/cacheable namespaces via compromised GitHub account</li>
<li>Combined weekly downloads of affected packages exceed 500 million</li>
<li>Steals npm, GitHub, AWS, Kubernetes and HashiCorp Vault credentials</li>
<li>Uses stolen npm tokens to auto-republish infected package versions</li>
<li>Exfiltrated data encrypted and sent via attacker HTTPS endpoint, with GitHub repos as fallback</li>
</ul>
