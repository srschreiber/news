### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Threat actors abuse ARTEX AI framework for network penetration and exploitation
Since July 2026, threat actors including Storm-0940, Storm-3358, Onyx Sleet, Pearl Sleet, Crystal Typhoon, and Salt Typhoon have weaponized the ARTEX AI framework to accelerate network reconnaissance, credential attacks, and exploitation. ARTEX automates penetration testing at machine speed and can advance from reconnaissance to privileged access in minutes.

<li>Automates existing pen-testing tools; threat actors vary IP, user agent to bypass detection</li>
