### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Microsoft Warns of Phishing Attacks Exploiting Recent Outage
Microsoft warned of an active phishing campaign exploiting a November 12 Exchange Online outage. Attackers impersonated service health notifications, falsely claiming messages would be deleted within 24 hours, and used legitimate incident reference numbers to appear authentic. The emails contained tracking links redirecting to credential-harvesting pages.

<ul class="takeaways">
<li>Campaign originated from three sender domains: moments-notice.com, planetmaison.com, newbooker.com</li>
<li>Referenced legitimate incident EX1550543 to appear authentic</li>
<li>Redirected users to reallifeaccounting.com/themelist0.html via SendGrid tracking links</li>
<li>Microsoft confirmed credential phishing but no confirmed credential theft or malware delivery yet</li>
<li>Use Microsoft Defender for Office 365 Threat Explorer to identify suspicious emails</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> SCKit malware abuses ScreenConnect remote access software
ConnectWise and Microsoft confirmed a campaign beginning November 11 where threat actors exploited unauthorized ScreenConnect access to install SCKit malware on managed service provider endpoints. The worm establishes persistence and deploys RelayTrap to target IT technician workstations, enabling attackers to distribute payloads across managed networks.

<ul class="takeaways">
<li>Attack began November 11, 2026 targeting MSP cloud-hosted ScreenConnect instances</li>
<li>SCKit worm uses scheduled tasks and registry Run entries for persistence</li>
<li>RelayTrap component targets IT support technician workstations via authenticated ScreenConnect sessions</li>
<li>Attackers issue commands through compromised ScreenConnect to silently install unauthorized remote-access clients</li>
<li>Enables remote administration and further tool deployment across victim&#x27;s managed endpoints</li>
</ul>
