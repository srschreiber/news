### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Threat actors weaponize GSocket for stealthy Linux command-and-control persistence
Microsoft Security detected multiple incidents where threat actors deployed GSocket, an open-source remote access tool, on compromised Linux servers to maintain persistent access after patching. GSocket relays traffic through shared public networks, eliminating need for attacker-controlled infrastructure detectable by defenders.

<ul class="takeaways">
<li>GSocket: open-source remote access tool deployed as C2 persistence mechanism</li>
<li>Relays traffic through shared public network; no attacker IP/domain to block</li>
<li>Activity concentrated on web applications and hosting environments</li>
<li>Avoids traditional detection methods (SSH keys, reverse shells, custom implants)</li>
<li>Activity increased over recent months</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Linux kernel vulnerabilities uncovered through AI-assisted research yield 59 bug reports
Microsoft's FORGE Lab used AI-assisted tool MDASH to scan Linux kernel subsystems in three months (late May to mid-June 2026), producing 59 public bug reports, 33 CVE assignments, and 38 merged fixes. Eight CVEs had confirmed root privilege-escalation exploits.

<ul class="takeaways">
<li>Three-month effort: 59 bug reports, 33 CVEs assigned, 38 kernel fixes merged</li>
<li>26,502 raw findings generated in 2 weeks; reduced to 11,769 candidates after filtering</li>
<li>8 of 33 CVEs had confirmed root privilege-escalation exploits</li>
<li>621 proof-of-concept cases tested in QEMU; expert review completed</li>
<li>Scanned subsystems: networking, filesystems, security modules</li>
</ul>
