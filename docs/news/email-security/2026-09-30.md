### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Star Blizzard refines phishing and malware delivery with RedFlick technique
Microsoft has documented Russian state-sponsored actor Star Blizzard evolving its attack capabilities since January 2026 through large-scale phishing campaigns and a new malware delivery technique called RedFlick. This technique uses scheduled tasks to deploy the CosmicPulse backdoor with a single user interaction, reducing friction compared to previous ClickFix-based chains and improving the actor's ability to compromise targets.

<ul class="takeaways">
<li>RedFlick requires only a single user interaction versus multiple actions needed for previous ClickFix-based infection chains</li>
<li>Star Blizzard shifted toward large-scale phishing operations in 2026 alongside RedFlick adoption</li>
<li>Targets include Ukrainian individuals and institutions, international NGOs, Western think tanks, and governments with Ukraine-related nexus</li>
<li>RedFlick deploys CosmicPulse backdoor through scheduled tasks to evade detection</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> CVE-2026-73570: Zimbra unauthenticated command injection in mail servers
Microsoft Threat Intelligence identified CVE-2026-73570, an unauthenticated command injection flaw in Zimbra mail servers' SNMP notification system under active exploitation. Attackers deployed web shells, reverse shells, and harvested email and authentication data from affected organizations.

<ul class="takeaways">
<li>CVE-2026-73570: unauthenticated OS command injection in Zimbra SNMP path</li>
<li>No authentication or user interaction required for exploitation</li>
<li>Affected internet-facing Zimbra servers with optional zimbra-snmp package installed</li>
<li>Post-exploitation activity included web shells, privilege escalation, data theft</li>
<li>Targeted organizations across multiple regions and industries</li>
</ul>
