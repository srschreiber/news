### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Attackers exploit Zimbra flaw to deploy web shells and steal authentication data
Threat actors weaponized CVE-2026-73570, an unauthenticated command injection flaw in Zimbra Collaboration Suite (CVSS 8.9), to deploy web shells and steal mailbox credentials. Zimbra patched the vulnerability in July 2026 (version 10.1.20). Exploitation occurred between July 20 and August 13 across multiple regions and industries, with CISA mandating federal remediation by August 24.

<ul class="takeaways">
<li>CVE-2026-73570: unauthenticated OS command injection (CVSS 8.9)</li>
<li>Affects systems with SNMP notifications and optional zimbra-snmp package</li>
<li>Patched July 2026 (version 10.1.20); active exploitation July 20–Aug 13</li>
<li>Attackers deployed JSP shells, harvested credentials, installed persistence tools</li>
<li>CVE-2026-73570: unauthenticated OS command injection in Zimbra SNMP path</li>
<li>No authentication or user interaction required for exploitation</li>
<li>Affected internet-facing Zimbra servers with optional zimbra-snmp package installed</li>
<li>Post-exploitation activity included web shells, privilege escalation, data theft</li>
<li>Targeted organizations across multiple regions and industries</li>
</ul>
