### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Google AitM phishing kit uses WebSockets to bypass multi-factor authentication in real time
Security researchers identified an advanced phishing campaign targeting Taiwan-based institutions using AI-generated emails and a sophisticated WebSocket-based adversary-in-the-middle framework that intercepts credentials and MFA challenges in real time. The threat actor used QR code injection and targeted organizations including Taiwan's European Union Centre and Institute of International Relations.

<ul class="takeaways">
<li>AI-assisted content generation created personalized phishing emails impersonating legitimate Taiwanese institutions</li>
<li>WebSocket architecture enabled real-time interception of MFA challenges and credentials</li>
<li>QR code phishing (quishing) modified legitimate event posters with malicious codes</li>
<li>Developer&#x27;s primary language likely Simplified Chinese based on UI analysis</li>
<li>Campaign targeted research organizations; no confirmed successful compromises</li>
</ul>
