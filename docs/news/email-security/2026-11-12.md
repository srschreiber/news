### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Post-training supply chain attacks hijack AI coding agents via poisoned datasets and checkpoints
Microsoft Security Research demonstrated how poisoned training data and compromised model checkpoints enable remote code execution in AI coding agents. Dataset poisoning achieved approximately 78% attack success rate, while model poisoning builds persistent backdoors triggered by routine user requests.

<ul class="takeaways">
<li>Dataset poisoning achieved ~78% success rate on test harnesses</li>
<li>Hidden behavior activated by routine paraphrased user requests</li>
<li>Backdoors enable remote code execution, file modification, tool invocation</li>
<li>Study emphasizes need for independent observability beyond model evaluation</li>
</ul>
