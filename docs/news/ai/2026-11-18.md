### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Google discovers previously unknown AI adversarial attack methods without human guidance
Google researchers discovered threat actors using autonomous AI agents to conduct cyberattacks without human intervention. In its quarterly AI threat tracker report, Google Threat Intelligence Group identified attackers using large language models (LLMs) to automatically compare web application code before and after security patches, identify vulnerabilities, develop working exploits, and execute them autonomously. The LLMs also generated scripts for follow-up activities including reconnaissance, brute-force attacks, and web shell malware installation. This represents an escalation from May when Google had previously observed AI assisting with vulnerability discovery and exploit generation. A specific August attack targeted Australian print management software PaperCut, where LLMs tested known vulnerabilities, compiled target lists, and conducted a widespread hacking campaign against hundreds of organizations. According to Google Threat Intelligence Group senior analyst Kelli Vanderlee, this marked the first identified example of threat actors using LLMs to automate the full cycle of vulnerability discovery, exploit code writing, and exploitation to gain unauthorized access. Researchers noted such autonomous AI agents can now explore multiple attack paths, troubleshoot errors, and achieve objectives in seconds and minutes, representing what Vanderlee characterized as a 'critical inflection point for defenders.'

## Security

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> PROMPTFLUX and PROMPTSTEAL malware target LLM APIs through direct calls
PROMPTFLUX and PROMPTSTEAL are malware variants that exploit large language model APIs by making direct calls to LLM services. The malware triggers unauthorized model usage through API calls at the gateway and on-site. The attack vectors target LLM API security and operate through prompt injection techniques. These represent the first documented malware variants specifically designed to compromise LLM API endpoints rather than traditional software targets.
