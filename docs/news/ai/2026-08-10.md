Meta released Muse Glimmer, a 30-billion-parameter open-weight AI model that can run locally on consumer hardware for agentic tasks like coding and tool use, without needing cloud infrastructure.

<ul class="takeaways">
<li>Apache 2.0 license, weights available on Hugging Face</li>
<li>~12GB memory needed after 4-bit quantization</li>
<li>Supports 100+ languages and multimodal (text and image) input</li>
<li>Benchmarked against Gemma4-31B and Qwen3.6-27B</li>
<li>llama.cpp, MLX, ExecuTorch integrations coming soon</li>
</ul>
