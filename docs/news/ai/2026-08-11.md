### <span class="imp imp-4" title="Importance 4/5" aria-label="Importance 4 of 5"><i class="on"></i><i class="on"></i><i class="on"></i><i class="on"></i><i></i></span> Meta Releases Muse Glimmer, 30B Open-Weight Model Signaling Return to Open-Source AI
Meta has released Muse Glimmer, a 30-billion parameter open-weight language model with a 120K+ context window designed to run locally on consumer hardware. The release marks Meta's significant return to the open-source AI ecosystem after more than a year and demonstrates the viability of running capable agentic AI workloads on-device, reshaping the competitive landscape between proprietary and open models.

<ul class="takeaways">
<li>Meta released Muse Glimmer, a 30B open-weight dense model with 120K+ context window</li>
<li>The model is designed for local, on-device deployment and agentic AI workflows on consumer hardware like NVIDIA GPUs</li>
<li>This represents Meta&#x27;s first major open-weight model release in over a year</li>
<li>Independent testing shows a 122B variant achieving 80/100 performance parity with Claude while costing 787× less per task</li>
</ul>
