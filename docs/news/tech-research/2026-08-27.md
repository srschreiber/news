## Security

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> MIT researchers discover processor security gap exploitable for privilege escalation
MIT CSAIL researchers disclosed TONTOU, a processor security vulnerability exploiting a timing gap between when CPU prediction machinery is wiped and when protections take effect. The attack uses interrupt injection to re-contaminate the processor's prediction machinery before defenses activate, successfully tested against Intel and AMD generations and demonstrated extracting a Linux system's password file.

<ul class="takeaways">
<li>TONTOU (Time-Of-Check-Time-Of-Use for On-chip Prediction Units)</li>
<li>Affects Intel and AMD processor generations</li>
<li>Defeats both software and silicon-based security mechanisms</li>
<li>Interrupt injection forces execution during vulnerability window</li>
<li>Successfully extracted Linux system password file</li>
<li>Undermines Spectre-era CPU security assumptions since 2018</li>
<li>Researchers: Daniël Trujillo and Mengjia Yan (MIT CSAIL)</li>
</ul>
