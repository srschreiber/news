## LLM Efficiency

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Galahad-KV: 50-Million-Token Memory Window for LLMs with Improved Speed and Cost
Galahad-KV is a memory layer enabling 50-million-token context windows by storing key-value states to encrypted NVMe disk instead of recomputing. Testing on NVIDIA H100 showed 2.8–4.3x faster loading and 8.8–12.3x lower energy than recomputation.

<ul class="takeaways">
<li>50-million-token context window on single NVIDIA H100 GPU</li>
<li>KV block loading 2.8–4.3x faster than recomputation</li>
<li>GPU energy consumption 8.8–12.3x lower for loaded vs. recomputed blocks</li>
<li>GPU memory remained flat across entire 50M-token stream</li>
<li>Works with Gemma 4 12B and 31B models; requires terabyte-scale NVMe storage</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> SAIL: 3.5B-Parameter Scientific Agent for Literature and Research Workflows
SAIL is an open-weight scientific model with 35 billion total and 3 billion active parameters designed for literature research, scientific coding, and multi-step workflows. Trained via science-aware agentic improvement loops examining task failures across search, reasoning, and planning.

<ul class="takeaways">
<li>3.5 billion active parameters (35B total), open-weight model</li>
