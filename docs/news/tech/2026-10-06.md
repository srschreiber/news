### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Type One Energy secures $200M to build commercial fusion power plant by 2034
Type One Energy raised $200 million in Series B funding to build Infinity Two, a 400-megawatt commercial fusion power plant operational by 2034. The funding covers approximately half the capital needed; the company will use an integrator model with specialized suppliers to reduce costs.

<ul class="takeaways">
<li>$200 million Series B funding announced October 6, 2026</li>
<li>400-megawatt commercial fusion power plant (Infinity Two) operational target: 2034</li>
<li>Funding covers ~50% of capital needed; subsequent rounds expected</li>
<li>Integrator business model: design plant and components, contract specialized suppliers for manufacturing</li>
<li>Partners: Commonwealth Fusion Systems (high-temperature superconducting magnets), AECOM (infrastructure)</li>
<li>First two fusion devices at Tennessee Valley Authority&#x27;s Bull Run site in Tennessee</li>
</ul>

## Security

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Atlassian Data Center Products Vulnerable to Unauthenticated File Access Exploit
Atlassian warned of CVE-2026-21589, a critical arbitrary file access vulnerability (CVSS 9.3) affecting eight Data Center products. Unauthenticated attackers can access specific files in the web application root if the exact path is known; Atlassian Cloud users are unaffected.

<ul class="takeaways">
<li>CVE-2026-21589 (CVSS 9.3) affects eight Atlassian Data Center products</li>
<li>Unauthenticated file access if exact filename and path known; no directory listing possible</li>
<li>Affected products: Bitbucket, Confluence, Jira Service Management, Jira Software, Bamboo, Crowd, Crucible, Fisheye</li>
<li>Atlassian Cloud SaaS already patched and unaffected</li>
<li>Atlassian recommends immediate upgrade or restrict external network access until patched</li>
</ul>
