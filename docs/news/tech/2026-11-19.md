### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Ruby2shell: Pre-Authentication RCE Vulnerability in Ruby on Rails
Ruby2Shell (GHSA-34m4-m9fh-gqp5) is a critical one-byte heap overflow in Ruby's string case conversion functions, exploitable without authentication in Ruby on Rails and Sinatra. Versions 3.3.14, 3.4.13, and 4.0.10 include fixes; vulnerable versions are 3.3.0–3.3.13, 3.4.0–3.4.12, and 4.0.0–4.0.9. The flaw has existed since Ruby 2.4.0.

<ul class="takeaways">
<li>Critical one-byte heap overflow in upcase, swapcase, downcase(:fold), casecmp? functions</li>
<li>Affects single-byte encodings (ISO-8859-*, Windows-125x); UTF-8 unaffected</li>
<li>Vulnerable Ruby versions: 3.3.0–3.3.13, 3.4.0–3.4.12, 4.0.0–4.0.9</li>
<li>Flaw existed since Ruby 2.4.0 (pre-authentication RCE in Rails/Sinatra default configs)</li>
<li>Affected systems: GitLab 19.6.0, GitHub Enterprise 3.22.5, Chatwoot 4.20.0</li>
</ul>
