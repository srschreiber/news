## Security

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Meta's Muse AI assistant exploited by simple ClickFix zero-day attack
Meta's Muse AI assistant, a macOS application, contains a critical zero-day vulnerability exploitable via simple ClickFix attack that allows any locally installed app or terminal command to access the authentication token granting complete account control.

<ul class="takeaways">
<li>Muse integrates with WhatsApp, email, calendar, social media; books appointments, fills forms, handles customer service, generates images</li>
<li>Zero-day allows access to authentication token by changing transcription endpoint to attacker-controlled server</li>
<li>Vulnerability bypasses macOS security defenses for app/terminal resource access (file writing, microphone, camera, location, calendar monitoring)</li>
<li>Amazon began blocking Muse from its site on September 21, 2026</li>
<li>Meta CEO Zuckerberg had claimed Muse &#x27;built from the ground up for privacy and security&#x27;; Meta did not respond to comment requests</li>
</ul>

Sources: [Ars Technica](https://arstechnica.com/security/2026/09/muse-metas-extraordinarily-privileged-ai-assistant-has-a-serious-0-day/) <span class="src-badge src-research">AI Web Searched</span>
