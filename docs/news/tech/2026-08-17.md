Apple patched the flaw on August 6 in emergency updates across three macOS versions.

<ul class="takeaways">

<li>Attackers deployed Monero miners with root access</li>
<li>Bypasses hardening measures and macOS TCC (Transparency, Consent and Control) protections</li>
<li>Patched August 6, 2026 in macOS Tahoe 26.6.1, Sequoia 15.7.9, Sonoma 14.8.9</li>
<li>Discovered by security researcher Alfredo Pesoli of Bynario</li>
<li>Vulnerability in macOS Screen Sharing authentication</li>
<li>Active exploitation deployed Monero miners</li>
<li>Exploitation accelerated after public exploit code release</li>
<li>CVE-2026-65400; CVSS 7.1/10; affects macOS screen sharing</li>
<li>Exploited when port 5900 exposed to internet; enables arbitrary code execution and root access</li>
<li>Active abuse observed by NCSC installing Monero miners</li>
<li>Apple patched macOS Tahoe, Sequoia, Sonoma last week</li>
<li>Details disclosed at Black Hat; mitigation: disable screen sharing, block port 5900, or tunnel via VPN/SSH</li>
