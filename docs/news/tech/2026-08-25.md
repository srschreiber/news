### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Sleepwalker Windows backdoor shows signs of sophisticated, well-resourced threat actors
Security researchers discovered Sleepwalker, a sophisticated Windows backdoor with 23 custom commands hidden inside a spoofed DLL, indicating development by a well-resourced threat actor. The passive malware remains dormant until activated by a specific network packet and uses in-memory code execution to evade detection.

<ul class="takeaways">
<li>Sleepwalker backdoor contains 23 custom instructions in proprietary command language</li>
<li>Masquerades as Microsoft&#x27;s dpapi.dll, exports same seven legitimate functions</li>
<li>Loads via side-loading into ESET Management Agent (ERAAgent.exe)</li>
<li>Passively monitors network packets for activation pattern; supports VMware VMCI targets</li>
<li>Dormant in memory to avoid antivirus detection; reverse-engineering required to decode commands</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Malware Distributed via Fake OpenAI Codex Sponsored Search Results
Attackers are distributing ClickFix malware to macOS developers through fraudulent Google search ads impersonating OpenAI Codex. The fake ads lead to a Google Sites page instructing users to paste a terminal command that decodes and executes attacker-controlled shell scripts, bypassing macOS security warnings.

<ul class="takeaways">
<li>Campaign targets macOS developers searching for Codex downloads via sponsored Google results</li>
<li>Fake page on Google Sites instructs users to run terminal command with Base64-encoded URL payload</li>
<li>Script removes macOS security information, bypassing typical download warnings before launching</li>
<li>Final malware is universal Mach-O executable running natively on Intel and Apple Silicon</li>
<li>Substantial similarities to Atomic macOS Stealer (AMOS) infostealer</li>
</ul>
