### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> ScreenConnect Plugin Flaw Exploited to Deploy Malware Across Hundreds of Systems
ConnectWise has disabled third-party extensions in hundreds of customer environments after hackers exploited an authentication bypass vulnerability in the ScreenConnect plugin ecosystem. Security firm Huntress first detected the active campaign on November 12, 2026, tracking attacks on at least 288 machines across 48 organizations within 90 minutes. The attackers used ScreenConnect's remote command feature to deploy a 16-file malware toolkit called SCKit, which installs a rogue ScreenConnect client for persistent remote access and includes code to spread infections to IT technicians and their customers. The vulnerability exists in RMM+, a third-party extension that allows external management tools to issue commands through ScreenConnect without using the console. Versions 1.0.31 and 1.0.32 of RMM+ accept a blank access key on installations without a configured key, bypassing ScreenConnect's normal user accounts and authentication controls—potentially allowing command execution without defeating MFA. Huntress suspects additional compromised MSPs exist based on sequential numbering of victim machines detected, indicating earlier undetected attacks.
