### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Microsoft: Chinese and North Korean Hackers Using ARTEX AI Tool to Breach Global Tech Systems
Microsoft reported that state-sponsored hackers from China and North Korea are exploiting ARTEX, an open-source AI-powered penetration testing framework publicly released in July 2026, to attack global technology infrastructure. Over 130 ARTEX variants circulate, making it the most widely used agentic offensive framework.

<ul class="takeaways">
<li>ARTEX automates reconnaissance, credential attacks, and exploitation</li>

<li>Campaigns reached privileged access in under 3 hours in some cases</li>
<li>130+ ARTEX variants in circulation; most widely used agentic offensive framework</li>
<li>Originally released July 2026 with Chinese-language interface; multiple language forks remain available</li>
</ul>

## Security Breach

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> 1Password suffers data breach via compromised GitHub account
1Password suffered a data breach on November 19 when an attacker compromised an employee's GitHub account, accessed source code, injected malicious code into backend services, and obtained infrastructure secrets. Customer vaults, passwords, and Secret Keys were not accessed. 1Password rotated credentials and tightened system controls.

<ul class="takeaways">
<li>Breach occurred November 19 via compromised employee GitHub account</li>
<li>Attacker accessed source code, injected malicious code into backend, accessed CI/CD secrets</li>
<li>Exposed data: names, emails, account/user IDs, creation/sign-in dates, public keys, SRP parameters</li>
<li>Customer vault contents, account passwords, Secret Keys not compromised</li>
<li>Invitation/recovery code length increased from 6 to 10 alphanumeric characters</li>
<li>Breach discovered November 19, disclosed November 26</li>
<li>Attacker accessed customer names, emails, account creation/sign-in dates, public keys</li>
<li>Vault data, passwords, encryption keys, recovery keys, Secret Keys not compromised</li>
<li>Revoked stolen token, disabled GitHub account, deployed new detection tools</li>
<li>Users advised to watch for phishing via compromised email addresses</li>
</ul>

## Trade Policy

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Nvidia Pauses Chip Shipments to Southeast Asia as U.S. Tightens China Restrictions
Nvidia instructed manufacturing partners to halt server chip shipments to Malaysia, Singapore, Thailand, and Indonesia to comply with tightened U.S. export controls targeting China. The move follows the U.S. Commerce Department closing a loophole in November that allowed Chinese companies to access Nvidia chips remotely through Southeast Asian data centers.

<ul class="takeaways">
<li>Nvidia halted shipments to Malaysia, Singapore, Thailand, Indonesia</li>
<li>U.S. closed loophole allowing Chinese remote access to Nvidia chips via SE Asia data centers</li>
<li>Southeast Asian remote data centers supply ~24% of China&#x27;s AI computing power</li>
<li>Pause allows Nvidia to assess compliance with U.S. export requirements</li>
<li>Reflects tightened China restrictions in November 2026</li>
</ul>
