### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Italy Fines Meta €805 Million for Facebook Android Gallery Access Without Consent
Italy's data protection authority fined Meta €805 million on November 14 for a Facebook Android feature that accessed users' phone galleries without explicit consent. The feature was enabled by default since 2023, and Meta must within 60 days request separate consent, disable the feature by default, and report on remediation efforts.

<ul class="takeaways">
<li>Fine: €805 million (0.47% of Meta&#x27;s global revenue) issued November 14, 2026</li>
<li>Feature accessed phone galleries without explicit user consent since 2023</li>
<li>Feature enabled by default; Meta must disable by default within 60 days</li>
<li>Meta must request separate, specific consent within 60 days or feature cannot be enabled</li>
<li>Fine: €805 million (~$887 million) issued Nov 14, 2026</li>
<li>Affected: ~20 million Italian Android users</li>
<li>Feature: Facebook&#x27;s &quot;Get suggestions from gallery when browsing Facebook&quot; accessed personal gallery content without explicit consent</li>
<li>Violation: enabled by default; used generic app-wide consent rather than separate specific consent (Italian/EU ePrivacy Directive)</li>
<li>Meta compliance deadline: disable feature by default, implement separate consent within 60 days; report within 30 and 90 days</li>
</ul>
