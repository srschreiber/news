### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> iAuthFlow V2 phishing toolkit exploits passkeys for persistent access
iAuthFlow V2, a phishing toolkit sold on Russian-language cybercrime forums for $10,000 base price, enables attackers to maintain persistent access by silently registering attacker-controlled passkeys during authentication. Victims cannot revoke access through standard password resets or session revocation, as the registered passkey circumvents typical account recovery measures.

<ul class="takeaways">
<li>iAuthFlow V2 base price: $10,000 with additional modules sold separately</li>
<li>Attacker registers passkey during authentication, persisting through password resets and session revocation</li>
<li>Attack uses attacker-controlled server browser environment relaying victim&#x27;s credentials and auth responses</li>
<li>Device fingerprinting applied to target&#x27;s browser; all entries logged</li>
<li>Toolkit demonstrated against Gmail accounts; passkey module analysis performed without running malware</li>
</ul>
