## Security

### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> ChainDrop worm infects 444 npm packages via supply chain attack
A malware variant called Shai-Hulud has infected 444 npm packages in a large-scale supply chain attack, with a combined 2 billion monthly downloads. The worm spreads via tarballs to evade detection, activates when infected code opens in development tools, and exfiltrates credentials to rebuild and re-poison packages it gains access to.

<ul class="takeaways">
<li>444 npm packages infected; 2 billion combined monthly downloads</li>
<li>Spreads via tarballs, not source commits—evades code review detection</li>
<li>Activates by opening infected Git branches in VS Code or Claude Code</li>
<li>Steals npm tokens, cloud keys, and credentials from environment variables and memory</li>
<li>Self-replicates through rebuilt package tarballs to circumvent repository safeguards</li>
</ul>

<li>Casualty reports vary: 1–5 deaths; buildings collapsed particularly in Maumere and Sikka regency</li>
<li>Tsunami warning issued then lifted; waves less than 1 meter recorded in some areas</li>
<li>Dozens of aftershocks including magnitude 6.1; thousands evacuated to higher ground</li>
<li>Magnitude 7.7 earthquake; 10 km depth; 68 km north-northwest of Ende</li>
