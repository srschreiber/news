### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> GnuPG Warns of Critical GPGME Memory Vulnerability Exploitable via Malicious OpenPGP Keys
A critical double-free vulnerability in GPGME (CVE-2026-129975) can be exploited by malicious OpenPGP keys with long user IDs, potentially exposing data from applications like mail clients and Samba. GPGME 2.3.1 fixes the flaw; users must rebuild statically linked versions.

<ul class="takeaways">
<li>CVE-2026-129975: double-free in GPGME versions before 2.3.1</li>
<li>Triggered by OpenPGP keys with unusually long user IDs</li>
<li>Affects mail clients, XMPP clients, Samba, Gpg4win, GnuPG Desktop</li>
<li>Fixed in GPGME 2.3.1 and Gpg4win 5.1.2</li>
<li>Remote code execution potential not ruled out</li>
<li>CVE-2026-129975: double-free in GPGME before 2.3.1</li>
<li>Triggered by OpenPGP key with crafted very long user ID</li>
<li>Affects all GPGME as shared library, DLL, or static component</li>
<li>Discovered by Johan Carlsson, reported November 12</li>
<li>Fixed in GPGME 2.3.1 (November 19) and Gpg4win 5.1.2</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Exascale fusion simulation team named Gordon Bell Prize finalist for 2026
A team led by Elia Merzari of Pennsylvania State University and Argonne National Laboratory was named a 2026 Gordon Bell Prize finalist for exascale fusion simulation of a water-cooled lead-lithium blanket for ITER. The simulations used 2 trillion grid points and 2 billion spectral elements—the largest liquid-metal magnetohydrodynamics simulations to date.

<ul class="takeaways">
<li>Gordon Bell Prize finalist for exascale fusion simulation work</li>
<li>Simulated water-cooled lead-lithium (WCLL) blanket for ITER fusion reactor</li>
<li>2 trillion grid points, 2 billion spectral elements: largest MHD simulations to date</li>
<li>Modeled six interacting processes including tritium transport and magnetic field effects</li>
<li>Developed MHD solver integrated into NekRS; aims to enable AI-driven design optimization</li>
</ul>
