### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> OpenAI Internal Repositories Compromised via Heap Overflow and SSO Misconfiguration
Security researchers exploited a heap overflow in an image decoder and SSO misconfiguration to breach OpenAI's internal code repositories, accessing employee accounts and the internal monorepo. The full exploit chain took under 72 hours; both OpenAI and Discourse patched within two months after disclosure on July 25.

<ul class="takeaways">
<li>Heap buffer overflow in libheif triggered via community forum image uploads</li>
<li>SSO misconfiguration allowed ChatGPT and Codex account takeover</li>
<li>Researchers accessed internal openai/openai monorepo, opened pull request #1186742</li>
<li>Exploit chain completed in less than 72 hours</li>
<li>$6,500 bounty awarded; patched within two months</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Hacktron Demonstrates Account Takeover Flaw in OpenAI Via AI-Generated Exploit
Hacktron researchers used Claude to develop an exploit for an unpatched libheif vulnerability in OpenAI's Discourse forum, chaining it with excessive sign-in token permissions to take over employee accounts and access internal repositories. The exploit demonstrated remote code execution and full API compromise.

<ul class="takeaways">
<li>Used Claude (Opus 4.8 and 5) to build working exploit for libheif vulnerability</li>
<li>Libheif bug fixed upstream a year earlier but never assigned CVE or security flag</li>
<li>Sign-in tokens for community forum carried excessive permissions to ChatGPT, Codex, GitHub, Slack, email</li>
<li>Researchers demonstrated account takeover by accessing OpenAI&#x27;s GitHub organization</li>
<li>Three-person Hacktron AI team exploited an ImageMagick/libheif vulnerability via HEIC image uploads</li>
<li>Sign-in tokens for OpenAI&#x27;s community forum carried excessive permissions to ChatGPT and Codex accounts</li>
<li>Libheif bug had been fixed upstream but never formally assigned a CVE number</li>
<li>OpenAI awarded $6,500 bug bounty; vulnerabilities resolved</li>
</ul>
