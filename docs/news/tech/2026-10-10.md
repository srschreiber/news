### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Telegram Desktop vulnerability exposed files to theft
A vulnerability in Telegram Desktop (CVE-2026-107181) allowed attackers to achieve one-click account takeover and steal arbitrary files through unescaped characters in the IPC mechanism. The flaw affected versions through 7.2.8 and was fixed in 7.2.9.

<ul class="takeaways">
<li>CVE-2026-107181 with CVSS score 8.1 (High)</li>
<li>One-click account takeover via malicious link click</li>
<li>Unescaped semicolon separator in IPC single-instance mechanism enabled command injection</li>
<li>Fixed in version 7.2.9; affected through 7.2.8 (Windows 6.9.3)</li>
<li>Attackers could steal session files and exfiltrate data without user confirmation</li>
</ul>
