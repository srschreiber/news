GitHub experienced a 7 hour 47 minute outage on August 17 when an Istio sidecar reached concurrency limits, saturating load balancers. A latent retry bug in VS Code amplified traffic approximately tenfold, overwhelming the Copilot Token Service and affecting multiple core services.

<ul class="takeaways">
<li>Outage duration: 1328–2115 UTC August 17, 2026 (7 hours 47 minutes)</li>
<li>Istio sidecar reached concurrency limit; autoscaling policy monitored only host service, not sidecar</li>
<li>VS Code retry bug amplified Copilot Token Service traffic by ~10x</li>
<li>Affected Issues, Pull Requests, APIs, Actions, Copilot; scraping attacks on codeload complicated recovery</li>
</ul>
