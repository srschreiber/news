### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> New cryptanalytic method breaks RSA encryption faster than factorization
Cryptographers led by UC San Diego professor Nadia Heninger discovered a classical computing method to break RSA encryption faster than factorization, using key and signature forgery techniques. Against 1024-bit keys, the attack required only months on an academic CPU cluster, reducing security levels far below the 128-bit NSA/NIST minimum standard.

<ul class="takeaways">
<li>Novel method breaks RSA without factorization requirement</li>
<li>1024-bit keys: months on academic CPU cluster; reduces security to 2^65</li>
<li>2048-bit keys: reduces security to 2^90; 4096-bit: reduces to 2^119</li>
<li>All below 128-bit NSA/NIST/EU minimum security standard</li>
<li>Attack works only against blind-signature RSA implementations; PKCS/PSS-padded RSA remains safe</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Salesforce Agentforce vulnerabilities enabled 0-click CRM data theft and anonymous phishing

The flaw exploited Web-to-Lead forms through indirect prompt injection, enabling silent data exfiltration under the agent's identity; Salesforce has since patched the issues.
