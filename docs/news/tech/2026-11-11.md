## AI Infrastructure

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Google Accelerates AI Performance by Removing Python from Query Pipeline
Google open-sourced XSE (XLA Serving Engine), which handles over six million queries per second for Search, Ads, and YouTube Shorts without Python in its serving pipeline. The C++ runtime delivers 2–5x throughput of optimized Python servers while using a quarter of the memory.

<ul class="takeaways">
<li>XSE handles 6+ million queries per second across Search, Ads, YouTube Shorts</li>
<li>2–5x throughput improvement vs. optimized Python; quarter the memory usage</li>
<li>Workflow: Python/JAX model code exported via StableHLO to C++ runtime with XLA compilation</li>
<li>Integration with TorchTPU planned for PyTorch users</li>
</ul>
