### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> AWS AgentCore Security Compromised by Credential-Stealing Prompt
AWS AgentCore's security is compromised by weak Firecracker MicroVM isolation, token exposure in Instance Metadata Service, and overly broad agent permissions that enable credential theft. An attacker with chat access to a single exposed agent can extract temporary credentials and take over all AgentCore agents within the same AWS account and region.

<ul class="takeaways">
<li>Vulnerabilities discovered December 2025; attacker with chat access to one agent can extract credentials from IMDS metadata</li>
<li>Extracted credentials allow enumeration and takeover of all AgentCore agents in same AWS account and region</li>
<li>Weak Firecracker MicroVM isolation, IMDSv1 (lacking IMDSv2 mitigations), overly broad agent permissions</li>
<li>Attacker can access ECR, pull agent container images, run as root, extract source code, inspect memory resources</li>
<li>Attacker can access user conversations and agent sessions</li>
</ul>
