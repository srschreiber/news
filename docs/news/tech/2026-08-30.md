### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Omarchy: Linux privilege escalation vulnerability allows users to gain root access
Omarchy Linux fixed a critical privilege escalation vulnerability (Omarchy) in versions prior to 4.0.1 that allowed any user process to gain root access without authentication. The flaw arose from default inclusion of user accounts in the docker group, enabling access to the Docker socket and root-level command execution.

<ul class="takeaways">
<li>Vulnerability affected all Omarchy versions prior to 4.0.1</li>
<li>Any user process could escalate to root without password or sudo prompt</li>
<li>Root cause: default docker group membership granting Docker socket access</li>
<li>Introduced June 1, 2025; removed from defaults August 24, 2026</li>
<li>Affected entire user session since supplementary groups inherited by child processes</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Critical arbitrary code execution vulnerability discovered in QubesOS
QubesOS released a critical security patch (QSB-118) for a code execution flaw in the qvm-copy-to-vm tool that allows attackers to inject commands into the system's trusted domain (dom0). The vulnerability exists in error reporting that unsafely processes filenames from compromised qubes, requiring the attacker to have already compromised a qube and for a user to initiate a copy operation to that qube.

<ul class="takeaways">
<li>QSB-118 fixes arbitrary code execution in qvm-copy-to-vm</li>
<li>Affects dom0 via unsafe filename handling in error reporting</li>
<li>Requires pre-compromised qube and user-initiated copy operation</li>
<li>Patches available through normal system updates</li>
</ul>
