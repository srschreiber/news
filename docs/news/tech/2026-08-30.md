## Security

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Critical arbitrary code execution vulnerability discovered in QubesOS
QubesOS released a critical security patch (QSB-118) for a code execution flaw in the qvm-copy-to-vm tool that allows attackers to inject commands into the system's trusted domain (dom0). The vulnerability exists in error reporting that unsafely processes filenames from compromised qubes, requiring the attacker to have already compromised a qube and for a user to initiate a copy operation to that qube.

<ul class="takeaways">
<li>QSB-118 fixes arbitrary code execution in qvm-copy-to-vm</li>
<li>Affects dom0 via unsafe filename handling in error reporting</li>
<li>Requires pre-compromised qube and user-initiated copy operation</li>
<li>Patches available through normal system updates</li>
</ul>
