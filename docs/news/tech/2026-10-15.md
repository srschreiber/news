### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Cisco Secure Email Gateway Vulnerability Exploited in the Wild
Unauthenticated attackers can write arbitrary files and execute commands with root privileges on Cisco Secure Email Gateway systems.

<ul class="takeaways">
<li>CVE-2026-76519 allows unauthenticated remote command execution as root (CVSS 9.8)</li>
<li>Requires File Reputation service enabled and Content Scanner Tools version earlier than 25.3.0.5525</li>
<li>Fixed in AsyncOS 15.5.5-014, 16.5.0-780, and Content Scanner Tools 25.3.0.5525 or later</li>
<li>Active exploitation discovered October 2026; AsyncOS 16.0 requires migration to fixed release</li>
<li>CVE-2026-76519 rated CVSS 9.8; zero-day actively exploited in the wild</li>
<li>Flaw in Advanced Malware Protection; unauthenticated attacker executes root commands via malicious email attachment</li>
<li>Affects SEG physical/virtual appliances and Panorama where File Reputation service enabled</li>
<li>CISA added to Known Exploited Vulnerabilities; federal agencies have Saturday remediation deadline</li>
</ul>
