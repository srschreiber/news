### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Windows 0-Day Exploit 'SignDrop' Disclosed, Grants System Privileges
Researcher Nightmare Eclipse publicly disclosed SignDrop, a Windows zero-day exploit allowing local users to gain full System privileges by abusing interactions between the Common Log File System, Windows Defender, and Windows file permissions. The vulnerability affects Windows 11 26H2 and Server 2025 Experimental and ironically stems from a 2025 Microsoft patch against other CLFS vulnerabilities.

<ul class="takeaways">
<li>Affects Windows 11 26H2, 26H2 Experimental, Windows Server 2025 Experimental</li>
<li>Exploits CLFS interaction with Windows Defender and symbolic links</li>
<li>Allows privilege escalation to System level from ordinary user rights</li>
<li>Bypasses antivirus and EDR tamper protection mechanisms</li>
<li>Unintended consequence of October 2025 security patch</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Protein Drives Aging Without Triggering Inflammatory Response
Researchers identified granzyme K as a protein that drives aging in body tissues independently of inflammation. Mice engineered to lack the enzyme showed improved heart and liver function, reduced kidney damage, and less age-related liver stiffness and scarring, suggesting drugs targeting this protein could combat aging without impairing immune defenses.

<ul class="takeaways">
<li>Granzyme K drives aging independently of inflammatory response</li>
<li>Knockout mice showed improved heart and liver function</li>
<li>Reduced kidney damage and liver fibrosis observed</li>
<li>Potential for targeted drug development</li>
