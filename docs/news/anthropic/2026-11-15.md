### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Cursor Breach: Stolen Fireworks Key Trojanized Claude Extension
Hackers used a stolen Fireworks AI access key to compromise Anthropic's official Claude Code extension on Cursor's marketplace, affecting up to 5,000 users.

<ul class="takeaways">
<li>Malicious Claude Code extension v2.1.313 affected up to 5,000 users via Cursor marketplace</li>
<li>Malware: 66-line loader installing persistent SSH backdoor with attacker&#x27;s key (&quot;svc-telemetry&quot;)</li>
<li>Transmitted host reconnaissance (IP, hostname, OS, CPU, Git email) unencrypted to 134.209.82.225:8099</li>
<li>Installed platform-specific persistence: scheduled task (Windows), crontab (Linux), LaunchAgent (macOS)</li>
<li>Attacker obtained Fireworks AI credentials; method remains unclear; marketplace temporarily shut down</li>
</ul>
