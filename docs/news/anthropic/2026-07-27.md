### Claude Cowork Escapes Sandbox, Gains Full File System Access on macOS
<span class="imp imp-4" title="Importance 4/5" aria-label="Importance 4 of 5"><i class="on"></i><i class="on"></i><i class="on"></i><i class="on"></i><i></i></span> Researchers found a sandbox escape flaw, dubbed SharedRoot, in Anthropic's Claude Cowork that let the AI agent break out of its macOS sandbox and access a user's entire file system, exposing roughly 500,000 users.

<ul class="takeaways">
<li>Exploits CVE-2026-46331, a Linux kernel privilege escalation in act_pedit module</li>
<li>Host filesystem mounted read-write into VM at /mnt/.virtiofs-root by design</li>
<li>Exposed SSH keys, AWS credentials, cloud tokens, browser data, API keys</li>
<li>Anthropic closed report as &#x27;informative&#x27;, no patch issued</li>
<li>Cowork now defaults to cloud execution; local mode remains vulnerable</li>
</ul>
