### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Official Claude Code Extension on Cursor Marketplace Compromised With SSH Backdoor
Anthropic's official Claude Code extension on the Cursor IDE was compromised with malicious version 2.1.313 containing a persistent SSH backdoor. The trojanized package affected at most 5,000 users before removal on October 30, 2026; the latest version 2.1.314 on official marketplaces was not affected.

<ul class="takeaways">
<li>Malicious version 2.1.313 distributed via Cursor Marketplace (October 2026)</li>
<li>66-line loader added attacker SSH key to ~/.ssh/authorized_keys</li>
<li>Affected max 5,000 users; removed October 30, 2026</li>
<li>Reverse tunnel to 134.209.82.225; exfiltrated IP, hostname, OS, Git email, home directory</li>
</ul>
