### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> MikroTik Routers Compromised Via Unauthenticated Internet-Exposed SSH Access
Attackers are exploiting unauthenticated SSH access on internet-exposed MikroTik routers to gain full administrative control. CERT Polska warned of the vulnerability chain on September 5, 2026, with active attacks documented since at least September 2. MikroTik released patches for affected RouterOS versions.

<ul class="takeaways">
<li>Vulnerability termed &#x27;MikroTrick&#x27; involves two unidentified flaws bypassing SSH authentication</li>
<li>Affected RouterOS: 6.0.0–6.49.20, 7.0.0–7.23.3, 7.24.0–7.24.1</li>
<li>Patches released: 6.49.21, 7.23.5, 7.24.2</li>
<li>Attacks documented since at least September 2, 2026</li>
<li>Post-compromise indicators: Flagged status warnings, unknown accounts, ssh:-2@ pattern in logs</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> REVSTEALER Malware Modules Disable Windows Defenses to Enable Cryptocurrency Mining
Elastic Security Labs identified four previously unknown programs linked to REVSTEALER malware that disable Windows defenses and deploy cryptocurrency mining. The tools—ProManager, WinUpdate, SoftManager, and LockAppHost—persist after REVSTEALER's core stealer removes itself, with LockAppHost disabling Windows Update services and Defender protections to run a hidden miner.

<ul class="takeaways">
<li>Four new REVSTEALER-linked programs: ProManager, WinUpdate, SoftManager, LockAppHost</li>
<li>REVSTEALER: Windows information stealer sold commercially since February 2026</li>
<li>LockAppHost disables 5 Windows Update services, 11 scheduled update tasks, 2 malware removal tasks</li>
<li>ProManager steals wallet files and browser extensions, overlays attacker content</li>
<li>WinUpdate monitors clipboard, replaces cryptocurrency addresses with attacker&#x27;s</li>
<li>Findings published September 2, 2026</li>
</ul>
