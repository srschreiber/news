### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Bricksforge WordPress Plugin CVSS 10.0 Flaw Exploited in Active Attacks
A maximum-severity vulnerability (CVE-2026-85097, CVSS 9.8) in the Bricksforge WordPress plugin allows unauthenticated attackers to upload files and execute remote code. Active exploitation began October 7, 2026; patched version 3.1.8.10 was released for versions 3.1.8.9 and earlier.

<ul class="takeaways">
<li>CVE-2026-85097, CVSS 9.8: unauthenticated remote code execution via arbitrary file upload</li>
<li>Affects Bricksforge 3.1.8.9 and earlier; patched in version 3.1.8.10</li>
<li>Active exploitation detected October 7, 2026; two distinct attack patterns using automated tools and rotating proxies</li>
<li>Bricksforge used by ~6,000 websites; serves Bricks visual site builder with forms, animations, email designer, admin tools</li>
</ul>
