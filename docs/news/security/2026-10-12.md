### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> SonicWall SMA 1000 Critical Flaw Targeted in 135 Exploitation Attempts Post-Patch
Threat actors exploited a critical SonicWall SMA 1000 vulnerability (CVE-2026-102255, CVSS 10.0) involving pre-authenticated server-side request forgery within days of disclosure.

<ul class="takeaways">
<li>CVE-2026-83548: critical pre-authentication SSRF (CVSS 10.0); CVE-2026-83549: command injection</li>

<li>ShadowServer identified 420+ SMA 1000 devices exposed to public internet</li>
<li>Third confirmed zero-day exploitation wave in just over a year; CISA 72-hour patch mandate for federal agencies</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Bricksforge WordPress Plugin CVSS 10.0 Flaw Exploited in Active Attacks
A maximum-severity vulnerability (CVE-2026-85097, CVSS 9.8) in the Bricksforge WordPress plugin allows unauthenticated attackers to upload files and execute remote code. Active exploitation began October 7, 2026; patched version 3.1.8.10 was released for versions 3.1.8.9 and earlier.

<ul class="takeaways">
<li>CVE-2026-85097, CVSS 9.8: unauthenticated remote code execution via arbitrary file upload</li>
<li>Affects Bricksforge 3.1.8.9 and earlier; patched in version 3.1.8.10</li>
<li>Active exploitation detected October 7, 2026; two distinct attack patterns using automated tools and rotating proxies</li>
<li>Bricksforge used by ~6,000 websites; serves Bricks visual site builder with forms, animations, email designer, admin tools</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Ukraine destroys third Yandex data center, disrupting Russian digital services
Ukrainian drones struck three Yandex data centers over four days, with two shutting down completely and the third destabilized. The attacks disrupted Yandex Cloud (serving 64,000 customers), email, taxi, food ordering, payments, and third-party services including Russian TikTok. Yandex reached agreements with competitors to help customers migrate.

<ul class="takeaways">
<li>Three Yandex data centers struck: Sasovo (Oct 7–8), Kaluga (Oct 9), Vladimir (Oct 12); combined ~115 MW capacity</li>
<li>Sasovo and Vladimir facilities house Yandex supercomputers for AI training</li>
<li>Yandex Cloud serves ~64,000 customers; disruptions affected email, taxi, payments, Yandex Pay, Alice voice assistant, TikTok Russia</li>
<li>Yandex updated terms excluding liability for drone strikes; arranged customer migration with Selectel, K2Cloud, VK Cloud</li>
</ul>
