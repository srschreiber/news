### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Five critical WordPress security flaws enable account takeover and code execution
Five critical WordPress vulnerabilities (CVSS 9.8–10.0) were disclosed in WPMU DEV Dashboard, Avada, TranslatePress, Pods, and GiveWP, enabling authentication bypass, remote code execution, and complete site takeover. All affected versions remain unpatched as of the disclosure date.

<ul class="takeaways">
<li>CVE-2026-76581 (CVSS 9.8): WPMU DEV Dashboard ≤5.0.1 allows unauthenticated administrator access via Hub Single-Sign On bypass</li>
<li>CVE-2026-18431 (CVSS 9.8): Avada ≤7.16 with Fusion Builder ≤3.16 permits arbitrary file write and PHP code execution</li>
<li>CVE-2026-19632 (CVSS 9.8): TranslatePress ≤3.3.1 exposes plaintext password-reset URLs when automatic string saving enabled</li>
<li>CVE-2026-19598 (CVSS 9.8): Pods ≤3.3.9 allows unauthenticated privilege escalation to Administrator or user password overwrite</li>
<li>CVE-2026-82222 (CVSS 10.0): GiveWP ≤4.16.7.1 enables arbitrary command execution via PHP object injection with one donation form and payment gateway</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Critical Cosmos EVM flaw exploited across six blockchains before public disclosure
A critical vulnerability in the Cosmos EVM module was exploited to drain funds from six blockchains between August 20–25, 2026, before public disclosure, despite Cosmos Labs knowing of the flaw since April. The balance-handling flaw affected all versions below 0.6.2 and 0.7.0–0.7.2, with fixes released August 19 requiring coordinated network upgrades.

<ul class="takeaways">
<li>Critical vulnerability (GHSA-7g4w-cg88-2cq2) exploited across six blockchains</li>
<li>Affected versions: &lt;0.6.2 and ≥0.7.0 &lt;0.7.2</li>
<li>Cosmos Labs received bug report April 25, confirmed all chains vulnerable August 13</li>
<li>Flaw exploits unchecked subtraction in vesting account delegation reconciliation</li>
<li>Fixes (v0.6.2 and v0.7.2) require state-breaking, coordinated network upgrades</li>
</ul>
