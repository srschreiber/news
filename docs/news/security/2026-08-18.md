### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical GitLab GraphQL Vulnerability Allows Unauthenticated Project Deletion
GitLab patched a critical GraphQL vulnerability (CVE-2026-19478, CVSS 9.4) allowing unauthenticated attackers to delete or modify public projects and user data. A secondary CSRF weakness (CVE-2026-19650, CVSS 7.1) was also fixed; patched versions are 18.11.11, 19.0.8, 19.1.6, and 19.2.4.

<ul class="takeaways">
<li>CVE-2026-19478 (CVSS 9.4): unauthenticated project/data deletion via GraphQL</li>
<li>Affected versions: CE and EE 18.2–19.2</li>
<li>CVE-2026-19650 (CVSS 7.1): CSRF in GraphQL multiplex query handler</li>
<li>Patched on August 17, 2026; no public exploits as of August 18</li>
<li>Technical details planned for publication ~November 17, 2026</li>
</ul>
