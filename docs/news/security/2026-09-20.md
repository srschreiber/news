### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Malicious npm packages bypass install-script defenses with runtime injection
Malicious npm packages compromised the AsyncAPI organization on July 14, 2026, hiding code that executes at module-load time rather than installation—bypassing common security defenses. Five package versions were injected with malware that could harvest credentials and establish persistent command-and-control access.

<ul class="takeaways">
<li>Five @asyncapi package versions compromised on July 14, 2026</li>
<li>Runtime-injection attack bypasses npm install --ignore-scripts mitigation</li>
<li>Affected packages: @asyncapi/specs, @asyncapi/generator, @asyncapi/generator-components, @asyncapi/generator-helpers</li>
<li>Malware enables credential harvesting and persistent C2 access</li>
<li>Impacts developer workstations, CI/CD pipelines, and production services</li>
</ul>
