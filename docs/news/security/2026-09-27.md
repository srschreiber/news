### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Microsoft SharePoint Vulnerability CVE-2026-65660 Actively Exploited
CISA added CVE-2026-65660, a Microsoft SharePoint flaw under active exploit, to its catalog with a September 28 federal patching deadline.

<ul class="takeaways">
<li>CVE-2026-65660: Microsoft SharePoint code injection, CVSS 8.8, remote code execution, active attacks as of Sept 25</li>

<li>Works on vulnerable RouterOS 7.x builds; Bishop Fox confirmed complete administrative takeover</li>
<li>Federal agencies deadline: September 28, 2026 to patch CVE-2026-65660</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Two Unpatched Citrix NetScaler Zero-Day Vulnerabilities Exploited in Wild
Two unpatched zero-day vulnerabilities in Citrix NetScaler ADC and Gateway appliances enabling remote code execution are being actively exploited in the wild, according to security firm watchTowr reported September 26. Citrix has not confirmed the flaws or published fixes, leaving operators to choose between keeping appliances online, isolating them, or powering them off.

<ul class="takeaways">
<li>Two unpatched zero-day remote code execution vulnerabilities</li>
<li>Actively exploited in the wild before any patch existed</li>
<li>Distinct from CVE-2026-19490 (patched August 19)</li>
<li>Discovered during forensic investigations; exploitation occurred pre-patch</li>
<li>Citrix patches expected early week of September 28</li>
<li>No vendor bulletin or workaround available; future patches won&#x27;t show prior access</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> ShinyHunters Hackers Expanded Attacks to Oracle PeopleSoft and Google Systems
Google's Mandiant reported on September 26 that ShinyHunters (tracked as UNC6240) renewed mass-exploitation attacks against Oracle PeopleSoft, exploiting CVE-2026-35273 (CVSS 9.8) by bypassing web application firewalls. On September 22, the group defaced FBIjobs.gov using the same vulnerability and claimed it accessed FBI-managed AWS GovCloud servers, extracting 2–3 terabytes of data including home addresses and family details of current, former, and prospective agents.

<li>Initial exploitation May 27–June 9; over 100 organizations affected, ~68% universities</li>
<li>Oracle patch issued June 10</li>
<li>Renewed attacks: adapted exploit to bypass web application firewall rules</li>
<li>Affected dozens of systems across higher education, tech, healthcare, agriculture, transportation, government</li>
<li>September 22: defaced FBIjobs.gov using same vulnerability</li>
<li>Claimed 2–3 terabytes extracted; home addresses and family details of FBI personnel</li>
<li>Reuters could not independently corroborate FBI data claims</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Cloudflare fixes cross-tenant data exposure vulnerability in Containers
Cloudflare has patched a vulnerability in Containers and Sandboxes that allowed paid Workers account holders to access residual data from other customers' containers on the same host.

<ul class="takeaways">
<li>Flaw allowed reading residual disk data from other customers&#x27; containers on shared servers</li>
<li>Affected Cloudflare Containers and Sandboxes services</li>
<li>Linux thin provisioning allocated 64-kilobyte blocks; deletion returned blocks to pool unwiped</li>
<li>Testing found recoverable data on 18 of 24 tries across servers, 20 of 22 machines across 4 continents</li>
<li>Reported September 4; fixed in two steps, cleanup completed September 19; disclosed September 24</li>
</ul>
