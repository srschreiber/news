### COLDCARD hardware wallet RNG flaw linked to $88 million Bitcoin theft
<span class="imp imp-4" title="Importance 4/5" aria-label="Importance 4 of 5"><i class="on"></i><i class="on"></i><i class="on"></i><i class="on"></i><i></i></span> A flawed random number generator in COLDCARD hardware wallet firmware, dating back to 2021, let attackers predict wallet seeds and steal about $88.6 million in Bitcoin from thousands of wallets before a patch was released.

<ul class="takeaways">
<li>First wave: ~1,083 BTC ($70.2M) drained from 1,196 addresses in 41 minutes</li>
<li>Total stolen across three waves: ~1,367 BTC ($88.6M) from 4,585 addresses</li>
<li>Flaw traced to a software RNG fallback instead of intended hardware RNG</li>
<li>Affected Mk2, Mk3, Mk4, Mk5 and Q devices; some seeds had only ~72 bits of entropy</li>
<li>Coinkite patched firmware July 31, but existing exposed seeds still need migration</li>
</ul>

Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/coldcard-wallet-rng-flaw-likely-linked-to-88-million-bitcoin-theft/) <span class="src-badge src-research">Research</span>
