### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> MI5 warns 100+ UK-linked academics may have aided Chinese intelligence
MI5 issued a security alert on September 30, 2026, warning that more than 100 UK-linked academics have contributed to research funded by China's Ministry of State Security via the China General Technology Research Institute. The academics' work in AI, cybersecurity, and covert communications has bolstered Chinese intelligence capabilities; some contributors may be unaware of the funding source.

<ul class="takeaways">

<li>Research focus areas: artificial intelligence, cybersecurity, covert communications, steganography</li>
<li>Institutions, staff, and researchers continuing such collaboration could be prosecuted under National Security Act 2023</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Dutch Institute for Vulnerability Disclosure breached via Zammad 0-days
The Dutch Institute for Vulnerability Disclosure was breached on September 21, 2026, through two zero-day vulnerabilities in Zammad ticketing software. Attackers chained the flaws to achieve remote code execution, then privilege escalation, exposing volunteer contact details and CSIRT ticketing conversations containing vulnerability reports and IP addresses.

<ul class="takeaways">
<li>Breach detected September 22; occurred September 21, 2026</li>
<li>Two zero-day CVEs: CVE-2026-102489 (CVSS 8.7) and CVE-2026-102490 (CVSS 8.5 local, 9.4 chained)</li>
<li>CVE-2026-102489 affected Zammad 6.3.0–6.5.4; CVE-2026-102490 affected 1.5.0–7.1.0 alpha</li>
<li>Attack characterized as agentic AI-powered; exposed volunteer emails, CSIRT conversations, IP addresses</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Fortra patches critical vulnerabilities in BoKS
Fortra released patches for eight vulnerabilities in BoKS, its privileged access manager for Unix and Linux systems. Three critical-severity flaws enable authentication bypass, remote shell command execution as root, and remote memory corruption.

<ul class="takeaways">
<li>Eight vulnerabilities patched; three rated critical severity</li>
<li>CVE-2026-79901 (CVSS 9.9): authentication bypass via predictable Active Directory service account passwords seeded with Unix timestamp</li>
<li>CVE-2026-79898 (CVSS 9.1): command injection in crlserver allowing arbitrary shell commands as root via BCC and WSI APIs</li>
<li>CVE-2026-12627 (CVSS 9.8): stack buffer overflow in autoregistration functionality</li>
</ul>
