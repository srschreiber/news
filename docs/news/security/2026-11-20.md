### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Linux KVM Hypervisor Flaw Exposes 127GB of Host Memory on AMD Systems
CVE-2026-99312, a flaw in Linux's KVM hypervisor, allows guest virtual machines to read and write to host system memory on AMD servers with nested virtualization enabled, potentially exposing other customers' data on shared infrastructure. A researcher demonstrated access to approximately 127 GB of host RAM and demonstrated write capability on bare-metal hardware.

<ul class="takeaways">
<li>Access to ~127 GB host RAM from guest VM on AMD nested virtualization</li>
<li>Write capability demonstrated (32 chosen bytes into live kernel memory)</li>
<li>Affects only AMD KVM hosts; Intel-based KVM unaffected</li>
<li>Linux fix merged November 2, 2026; DigitalOcean patched November 19</li>
<li>Requires root access in guest VM; no public exploits released</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Ruby Patches Critical Ruby2Shell Heap Buffer Overflow Vulnerability
Ruby released security updates on November 20, 2026, addressing seven vulnerabilities including CVE-2026-132825 (Ruby2Shell), a heap-based buffer overflow in case conversion operations that could enable remote code execution. The flaw affects single-byte encodings like ISO-8859-1 and Windows-1252.

<ul class="takeaways">
<li>CVE-2026-132825 (Ruby2Shell) heap buffer overflow; CVSS 7.4</li>
<li>Affects case conversion in single-byte encodings (ISO-8859-1, Windows-1252)</li>
<li>Proof-of-concept code exists for 5 of 7 vulnerabilities</li>
<li>GitHub Enterprise Server, Chatwoot, GitLab, Mastodon affected; patched</li>
</ul>
