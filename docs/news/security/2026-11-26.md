### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> 1Password suffers data breach via compromised employee GitHub account
1Password disclosed a November 19, 2026 breach in which attackers exploited a compromised employee GitHub account to obtain source code and administrative customer data including names, emails, and account metadata. User vault contents remained secure due to 1Password's architecture where passwords and secret keys are not stored server-side.

<ul class="takeaways">
<li>Breach disclosed November 19, 2026</li>
<li>Compromised employee GitHub account provided source code and backend service access</li>
<li>Customer data obtained: names, emails, public keys, account creation/sign-in times</li>
<li>User vault content not compromised (passwords, secret keys not server-stored)</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Australia Passes Digital Duty of Care Act Requiring Tech Companies to Prevent Harms
Australia's Parliament passed the Digital Duty of Care Act on November 25, 2026, mandating online platforms establish protocols to protect users from violence, exploitation, and harmful content. Tech companies face potential billion-dollar fines for failing to preempt harms; users can opt out of algorithmic feeds and must age-verify for adult content.

<ul class="takeaways">
<li>Passed November 25, 2026 with PM Albanese backing</li>
<li>Platforms must detect/reduce harmful content; protect under-18 users from pornography, suicide, eating disorder content</li>
<li>Annual risk assessments required; must disclose major design changes like endless scrolling</li>
<li>Users can opt out of algorithmic feeds; age verification required for pornography; potential billion-dollar fines</li>
</ul>
