### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> North Korea-Linked PolinRider Campaign Poisons 7,600+ GitHub Repositories
North Korea-linked threat actors behind the PolinRider campaign have planted Python loaders in over 7,600 GitHub repositories since February 2025 to distribute malware. The campaign uses multiple entry vectors including fraudulent recruitment, account hijacking, and uses an Ethereum-based command-and-control infrastructure to execute infostealer malware targeting developer credentials.

<ul class="takeaways">
<li>7,600+ GitHub repositories poisoned since at least February 2025</li>
<li>SafeDep identified loader in 375 public repositories; 260 accounts affected</li>
<li>Loader executes JavaScript via Node.js after reading Ethereum wallet transactions for C2 location</li>
<li>Targets GitHub Desktop, Cursor, VS Code, Google Antigravity; delivers infostealer malware</li>
<li>Distribution via fraudulent recruitment, account hijacking, compromised developer machines</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Juniper Session Smart Conductor RCE Vulnerability Exploited
Juniper Networks and CISA warned that CVE-2026-103406, a critical remote code execution vulnerability in Session Smart Conductor, is being actively exploited. The flaw allows attackers to execute arbitrary commands as root by injecting malicious code through the Salt minion ID parameter, and CISA mandated federal agencies patch within three days.

<ul class="takeaways">
<li>CVE-2026-103406; CVSS 9.8 critical; active exploitation confirmed</li>
<li>Affects Session Smart Conductor and Session Smart Router</li>
<li>OS command injection in AutomationProvisioner service via Salt minion ID</li>
<li>Patched October 28, 2026 in versions 7.2.3, 7.1.7, 7.0.5</li>
<li>CISA added to KEV catalog; federal civilian agencies must patch within 3 days under BOD 26-04</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Australia Passes Digital Duty of Care Act Requiring Tech Companies to Prevent Harms
Australia's Parliament passed the Digital Duty of Care Act on November 25, 2026, mandating online platforms establish protocols to protect users from violence, exploitation, and harmful content. Tech companies face potential billion-dollar fines for failing to preempt harms; users can opt out of algorithmic feeds and must age-verify for adult content.

<ul class="takeaways">
<li>Passed November 25, 2026 with PM Albanese backing</li>
<li>Platforms must detect/reduce harmful content; protect under-18 users from pornography, suicide, eating disorder content</li>
<li>Annual risk assessments required; must disclose major design changes like endless scrolling</li>
<li>Users can opt out of algorithmic feeds; age verification required for pornography; potential billion-dollar fines</li>
</ul>
