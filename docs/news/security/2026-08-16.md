## Security

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Multiple high-severity TP-Link vulnerabilities enable authentication bypass and privilege escalation
TP-Link disclosed multiple high-severity vulnerabilities in Omada Gateway and Archer router devices enabling authentication bypass, arbitrary command execution, and privilege escalation. CVE-2025-6541 allows attackers to inject malicious payloads through unsafe web interface parameter handling, potentially leading to full device compromise and lateral movement within enterprise networks.

<ul class="takeaways">
<li>CVE-2025-6541: critical Remote Command Injection in Omada Gateway devices</li>
<li>Related vulnerabilities including CVE-2025-6542 enable remote control without authentication</li>
<li>Archer series routers affected by four additional high-severity vulnerabilities</li>
<li>Exploitation risks include credential theft, lateral movement, and privilege escalation in enterprise networks</li>
