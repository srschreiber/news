### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Sangoma Switchvox SQL Injection Flaw Exploited for Remote Code Execution
A critical unauthenticated SQL injection vulnerability (CVE-2026-9586, CVSS 9.3) in Sangoma Switchvox SMB Edition 8.3 allows remote attackers to execute arbitrary code as the PostgreSQL superuser without authentication. Approximately 4,000 instances are exposed to the internet, and active exploitation attempts deploying reverse shells were observed starting August 30, 2026.

<ul class="takeaways">
<li>CVE-2026-9586: unauthenticated SQL injection in Switchvox SMB Edition 8.3, CVSS 9.3</li>
<li>Patch released in Switchvox 8.4.0.2 on July 14, 2026</li>
<li>Approximately 4,000 instances exposed to the internet, mostly in U.S.</li>
<li>Active exploitation observed starting August 30, 2026; reverse shell deployment confirmed</li>
<li>Allows privilege escalation, cookie signing key extraction, arbitrary database operations</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Claude AI used to port pre-authentication RCE exploit between PLC models
Security researchers at Forescout Research used Anthropic's Claude to port a pre-authentication remote code execution exploit from one WAGO PLC model to another, demonstrating how AI can adapt existing vulnerabilities. The exploit targeting CVE-2021-31886 required sustained researcher steering and cost $535.74 in API usage over 8 hours 32 minutes to achieve working code execution.

<ul class="takeaways">
<li>Ported pre-authentication RCE exploit between WAGO PLC models using Claude</li>
<li>CVE-2021-31886: stack-based buffer overflow in Nucleus FTP server, CVSS 9.8</li>
<li>Exploit development cost $535.74 over 8 hours 32 minutes in API usage</li>
<li>Claude generated two functional payloads: ICMP echo and UDP packet delivery</li>
<li>No updates available for affected WAGO controllers; FTP port 21 blocking recommended</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> FBI Investigates Service Selling 153M+ Stolen Driver's Licenses
The FBI's New Orleans field office launched an investigation on September 1, 2026, into a dark web service called Nexus selling over 153 million digital scans of U.S. and Canadian driver's licenses. The proprietors claim the stolen documents come from an ongoing breach at a major Louisiana-based identity verification company serving Fortune 500 clients.

<ul class="takeaways">
<li>Over 153 million U.S. and Canadian driver&#x27;s licenses offered for sale</li>
<li>Also includes 10+ million ID cards, 3+ million travel documents, 579,000 medical cards</li>
<li>Database grew approximately 400,000 records in 24 hours</li>
<li>Records include front/back scans, infrared, ultraviolet formats with timestamps</li>
<li>Ontario represents 473,673 Canadian records; includes government official documents</li>
</ul>
