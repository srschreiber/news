### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> MiniOrange SAML Plugin Flaws Exploited to Gain WordPress Admin Access
Attackers are exploiting two critical authentication bypass vulnerabilities in the miniOrange SAML WordPress plugin to gain administrator access. The flaws stem from improper signature validation in the openssl_verify() function, allowing crafted malformed signatures to bypass verification and grant admin privileges.

<ul class="takeaways">
<li>CVE-2026-61979 (CVSS 8.1): unauthenticated privilege escalation via signature algorithm confusion</li>
<li>CVE-2026-15981 (CVSS 9.8): authentication bypass accepting malformed signatures as valid</li>
<li>Fixed in Standard edition versions 17.0.5 and 17.0.6 respectively</li>
<li>Loose boolean check treats -1 return value from openssl_verify() as successful verification</li>
<li>Proof-of-concept code publicly available; six IP addresses recorded scanning for vulnerable sites</li>
</ul>
