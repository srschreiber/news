### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Ancient BMC vulnerability CVE-2013-4786 exposes thousands of data centers to attacks
Over 24,000 internet-accessible servers running outdated Baseboard Management Controller firmware remain vulnerable to CVE-2013-4786, a 22-year-old flaw that allows remote attackers to extract password-derived authentication hashes for offline cracking. Nearly 37,000 internet-exposed IPMI interfaces are affected overall.

<ul class="takeaways">
<li>CVE-2013-4786: 22-year-old IPMI 2.0 authentication protocol vulnerability from 2004</li>
<li>Over 24,000 exposed BMC servers vulnerable; ~37,000 internet-exposed IPMI interfaces affected</li>
<li>Vulnerability allows extraction of HMAC-SHA1 authentication hashes from RAKP message 2 responses</li>
<li>Compromised credentials work across Redfish HTTPS API and web-based administrative interfaces</li>
<li>6,240 exposed hosts accept empty usernames with weak passwords</li>
</ul>
