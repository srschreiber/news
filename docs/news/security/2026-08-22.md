## Security

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Banking Trojans Manic, Grandoreiro, ToxicPanda 2.0 Tracked
Security researchers documented three active banking malware campaigns: Manic targets Ukrainian banks and government with spyware and keylogging; Grandoreiro continues a decade-long operation across Latin America, Europe, and North America using DLL sideloading; ToxicPanda 2.0 represents an expanded variant.

<ul class="takeaways">
<li>Manic: Android banking trojan plus spyware targeting Ukraine, Russia, Europe; includes offline mesh relay via Wi-Fi Direct or Bluetooth</li>
<li>Manic capabilities: keystroke logging, phishing screens, remote device control, notification monitoring, location tracking, file harvesting</li>
<li>Grandoreiro: Windows malware active 10+ years, recent campaigns focus on Mexico, abuses Duplicate Files Finder app for DLL sideloading</li>
<li>ToxicPanda 2.0: expanded malware variant tracked by security researchers</li>
</ul>
