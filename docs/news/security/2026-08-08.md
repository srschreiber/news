### Metabase zero-day SQL injection exploited in wild for data theft
<span class="imp imp-4" title="Importance 4/5" aria-label="Importance 4 of 5"><i class="on"></i><i class="on"></i><i class="on"></i><i class="on"></i><i></i></span> A maximum-severity, unpatched SQL injection flaw in Metabase was exploited in the wild to steal customer data, hitting companies including Framework and Tally before a patch was released.

<ul class="takeaways">
<li>CVSS 10.0 flaw affects Metabase versions 1.58 and above; no CVE assigned yet</li>
<li>Allowed unauthenticated attackers to gain admin access via SQL injection</li>
<li>Framework breach (Aug 3) exposed names, emails, IPs, addresses, phone numbers—no payment data taken</li>
<li>Tally breach exposed customer emails and password hashes</li>
<li>Fixed versions: x.58.24, x.59.21, x.60.17, x.61.11, x.62.9, x.63.5</li>
<li>Metabase blocked attack endpoints, patched Aug 7, and notified law enforcement</li>
</ul>
