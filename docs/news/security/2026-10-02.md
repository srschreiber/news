### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Critical FortiMail Zero-Day Flaw Exploited in Active Attacks
CISA added CVE-2026-104286, a critical FortiMail zero-day flaw (CVSS 9.8), to its Known Exploited Vulnerabilities catalog on October 2 following active exploitation reports. The path traversal vulnerability allows unauthenticated attackers to write arbitrary files via crafted HTTP requests.

<ul class="takeaways">
<li>CVSS score 9.8; active exploitation confirmed</li>
<li>Affects FortiMail 7.2.0–7.2.9, 7.4.0–7.4.8, 7.6.0–7.6.6, 8.0.0–8.0.1</li>
<li>No patches released; fixes promised in versions 7.4.9, 7.6.7, 8.0.2 (timeline not provided)</li>
<li>CISA mandated federal agencies address within 3 days under BOD 26-04</li>
</ul>

<li>DoD found no evidence of misuse; attackers unidentified</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Dell patches maximum severity vulnerabilities in Container Storage Modules
Dell released patches on October 1, 2026 for six critical and maximum-severity vulnerabilities in Container Storage Modules that integrate Dell enterprise storage with Kubernetes. Two CVSS 10.0 flaws allow unauthenticated attackers to extract administrator credentials for all registered storage arrays and bypass authentication to read or alter storage resources across all tenants.

<ul class="takeaways">
<li>Two CVSS 10.0 vulnerabilities (maximum severity): CVE-2026-63688 and CVE-2026-63692</li>
<li>CVE-2026-63688: unauthenticated extraction of backend admin credentials for all storage arrays</li>
<li>CVE-2026-63692: authentication bypass affecting all tenants&#x27; storage resources</li>
<li>Four additional 9.6–9.9 CVSS flaws enable root access, Kubernetes secret exfiltration, token forgery, and hardcoded credential misuse</li>
<li>No exploitation in the wild; no public proof-of-concept code released</li>
<li>Affects PowerStore, PowerScale, PowerFlex, PowerMax, Unity XT platforms</li>
</ul>
