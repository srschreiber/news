### Rails Critical RCE Vulnerability in Active Storage
<span class="imp imp-4" title="Importance 4/5" aria-label="Importance 4 of 5"><i class="on"></i><i class="on"></i><i class="on"></i><i class="on"></i><i></i></span> Rails patched a critical unauthenticated RCE vulnerability in Active Storage (CVE-2026-66066, CVSS 9.5), exploitable through malicious image uploads processed by libvips.

<ul class="takeaways">
<li>CVSS 9.5, unauthenticated attacker can read files and achieve RCE</li>
<li>Affects Active Storage before 7.2.3.2, 8.0.5.1, and 8.1.3.1</li>
<li>Exploitable when libvips generates thumbnails from untrusted uploads</li>
<li>Can expose Rails secret_key_base and database/cloud credentials</li>
<li>Fix: upgrade libvips to 8.13+, rotate secrets, or set VIPS_BLOCK_UNTRUSTED</li>
</ul>

Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/rails-patches-critical-active-storage-flaw-with-rce-potential/) <span class="src-badge src-research">Research</span>, [SecurityWeek](https://www.securityweek.com/ruby-on-rails-patches-critical-vulnerability/) <span class="src-badge src-research">Research</span>

### Adobe Campaign Classic CVSS 10.0 Critical Flaw

<ul class="takeaways">
<li>CVE-2026-48449: incorrect authorization flaw, CVSS 10.0, no auth or user interaction needed</li>

<li>Adobe says no active exploitation observed in the wild</li>
