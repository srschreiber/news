### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> FortiBleed vulnerability exploited to lock legitimate users out of Fortinet security appliances
The FortiBleed campaign has compromised approximately 86,644 Fortinet devices across 194 countries. Attackers lock organizations out of their appliances by changing passwords and deleting legitimate accounts, then maintain persistence for lateral movement within networks.

<ul class="takeaways">
<li>~86,644 devices compromised across 194 countries</li>
<li>Campaign active since June 2026</li>
<li>Attackers use credential harvesting, brute force, offline cracking</li>
<li>FBI and US Secret Service joint advisory issued</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Tensorlake npm package compromised by Shai-Hulud credential-stealing worm
The npm package tensorlake version 0.5.144 was compromised with obfuscated malware that harvests credentials from local files, CI environments, Kubernetes, and Vault. The worm steals API tokens, SSH keys, cryptocurrency wallets, and AI tool credentials, then republishes compromised versions.

<ul class="takeaways">
<li>Steals npm, GitHub, AWS tokens; SSH keys; Vault secrets</li>
<li>Exfiltrates Anthropic Claude, Cursor, VS Code credentials</li>
<li>Drops HackBrowserData binary for additional credential harvesting</li>
<li>Uses Ethereum contract for command-and-control resolution</li>
</ul>
