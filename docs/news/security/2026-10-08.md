### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Tensorlake npm package compromised by Shai-Hulud credential-stealing worm
The npm package tensorlake version 0.5.144 was compromised with obfuscated malware that harvests credentials from local files, CI environments, Kubernetes, and Vault. The worm steals API tokens, SSH keys, cryptocurrency wallets, and AI tool credentials, then republishes compromised versions.

<ul class="takeaways">
<li>Steals npm, GitHub, AWS tokens; SSH keys; Vault secrets</li>
<li>Exfiltrates Anthropic Claude, Cursor, VS Code credentials</li>
<li>Drops HackBrowserData binary for additional credential harvesting</li>
<li>Uses Ethereum contract for command-and-control resolution</li>
<li>Tensorlake SDK ~12,000 weekly downloads; GitHub repo 1,000+ stars</li>
<li>Shai-Hulud variant shares code with August 2026 ChainDrop malware</li>
<li>Malicious script executes on developer machine/build server before sandbox protections</li>
<li>Steals crypto keys, browser passwords, GitHub tokens, cloud/service-account credentials</li>
<li>Related to earlier compromises of keyv and flat-cache npm packages</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Cisco releases patches for critical NX-OS vulnerabilities enabling Nexus switch takeover
Cisco released patches for a critical vulnerability (CVE-2026-20212, CVSS 9.8) in Nexus 9000 Series switches with Silicon One ASICs. Unauthenticated remote attackers can execute arbitrary code with root privileges via TCP ports 43210–43211 exposed through default Layer 3 VRF, potentially crashing the S1HAL process.

<ul class="takeaways">
<li>CVE-2026-20212, CVSS score 9.8, unauthenticated remote code execution as root</li>
<li>Affects Nexus 9000 Series with Silicon One ASICs</li>
<li>Vulnerability in TCP ports 43210 and 43211 exposed via default Layer 3 VRF</li>
<li>Exploitation can crash S1HAL process, forcing device reload</li>
<li>Affected models: N9324C-SE1U, N9348Y2C6D-SE1U, N9364E-SG2-O/Q, N9396T12C-SE1, N9348Y12C-SE1, N9396Y12C-SE1, N9336C-SE1, N9K-C9804, N9K-C9808</li>
</ul>
