### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> CISA Flags Three Linux Kernel Vulnerabilities Under Active Exploitation
CISA added three actively exploited Linux kernel vulnerabilities to its Known Exploited Vulnerabilities catalog on September 19, 2026. CVE-2025-39682 (CVSS 9.8) allows local users to trigger memory disclosure or denial-of-service; CVE-2026-53266 (CVSS 8.8) enables privilege escalation; CVE-2025-39964 (CVSS 7.8) is a race condition in cryptographic operations.

<ul class="takeaways">
<li>CVE-2025-39682: CVSS 9.8, local authenticated users trigger memory disclosure/DoS</li>
<li>CVE-2026-53266: CVSS 8.8, out-of-bounds write enables privilege escalation</li>
<li>CVE-2025-39964: CVSS 7.8, race condition crashes system or corrupts crypto results</li>
<li>Red Hat issued advisories confirming active exploitation on September 19</li>
<li>Federal agencies recommended to apply fixes by September 21, 2026</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> McKesson Confirms Data Breach as Attacker Deadline Approaches
Healthcare distributor McKesson Corporation confirmed a cybersecurity incident discovered August 25, 2026, involving unauthorized data theft affecting customers in its Oncology & Multispecialty and Medical-Surgical units. ShinyHunters claimed responsibility, alleging theft of 284 million records and demanding $55 million ransom with a September 1 deadline.

<ul class="takeaways">
<li>Incident discovered August 25, 2026; confirmed August 31</li>
<li>ShinyHunters claimed 284 million records stolen</li>
<li>$55 million ransom demanded with September 1 deadline</li>
<li>Affected Oncology &amp; Multispecialty and Medical-Surgical units</li>
<li>McKesson delivers approximately one-third of North American prescription medicines</li>
<li>Offering complimentary credit monitoring and identity protection to impacted individuals</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> TanStack Supply Chain Attack Led CrowdSec Attacker to Copy 170 Private Repositories
An attacker exploited a departed employee's GitHub access—left open after May's TanStack supply chain attack—to copy approximately 170 of CrowdSec's private repositories on May 22. The repositories contained CrowdSec's web console, data science models, and consensus algorithm for IP blocklist determination; the leaked code surfaced September 16.

<ul class="takeaways">
<li>May 11, 2026: 84 malicious TanStack npm packages deployed (CVE-2026-45321)</li>
<li>Stolen credentials: GitHub tokens, SSH keys, cloud credentials from developer machines</li>
<li>May 22: Attacker copied ~170 CrowdSec private repositories using stolen token</li>
<li>CrowdSec removed account May 25 (three days after copy)</li>
<li>Leaked code surfaced September 16; disclosed September 18</li>
<li>Leaked 83 CrowdSec user emails and 51 potential investor names/emails from 2020</li>
<li>Code was approximately four months old at breach time</li>
<li>Also affected Mistral AI and OpenAI</li>
</ul>
