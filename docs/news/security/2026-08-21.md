### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> CISA Urges Immediate Patching of Actively Exploited TrueConf Vulnerabilities
CISA warned on 21 August 2026 that threat actors are actively exploiting two critical vulnerabilities in TrueConf video conferencing software to deploy PhantomCore malware. The flaws allow remote code execution and privilege escalation on unpatched TrueConf Server instances since 2022.

<ul class="takeaways">
<li>CVE-2026-72529 and CVE-2026-72530: critical-severity flaws in TrueConf Server</li>
<li>Affect all versions from 2022; patched in June 2026 (5.3.9, 5.4.9, 5.5.5)</li>
<li>Exploit vector: remote access via port 4307/TCP</li>
<li>Actively exploited by hacktivist group Head Mare to deploy PhantomCore malware</li>
<li>CISA KEV catalog: federal agencies must patch within 3 days (72529) or 2 weeks (72530)</li>
</ul>
