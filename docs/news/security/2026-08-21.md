### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Rust Supply Chain Attack Compromises Three Popular Crates with 245M Downloads
The Rust Project removed malicious versions of three widely-downloaded crates published by a compromised maintainer account that injected a typosquatted dependency with a remote-executing build script.

<ul class="takeaways">
<li>arrayref crate: 244 million downloads compromised</li>
<li>Infostealer malware executes at developer compile time</li>
<li>append-only-vec also targeted in same attack</li>
<li>Supply chain compromise of widely-used Rust ecosystem packages</li>
<li>Malicious arrayref v0.3.10 published August 20, 2026 on crates.io</li>
<li>Depends on typosquatted crate proc-macro1 executing remote binary at build time</li>
<li>Maintainer account droundy compromised; GitHub repos now unavailable (404)</li>
<li>proc-macro1 published by dtolney account forging David Tolnay authorship</li>
<li>Crates.io team removed malicious versions</li>
</ul>
