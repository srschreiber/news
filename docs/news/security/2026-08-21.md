The bug exploits a time-of-check/time-of-use weakness where JavaScript array getters can return different values across iterations, allowing attackers to dereference attacker-controlled pointers and hijack host process control flow.

<li>Successful exploitation causes denial-of-service crash or host process control-flow hijacking</li>
<li>CVE identifier not yet assigned</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Microsoft Defender driver can be weaponized to disable security software at boot
Check Point Research disclosed a technique exploiting Microsoft Defender's legitimate boot-time driver to perform arbitrary kernel operations and disable security software on Windows 7 through Windows 11 systems. The RC4-encrypted driver cannot be blocked without disrupting Defender itself, and the proof-of-concept was demonstrated at Black Hat USA 2026.

<ul class="takeaways">
<li>Affects Windows 7 through Windows 11 25H2</li>
<li>RC4 encryption key hard-coded in BTR.sys, unchanged across 18+ versions</li>
<li>Exploitation requires administrator account with SeLoad privilege</li>
<li>Bypasses Service Control Manager and generates no Windows Event ID 7045</li>
<li>Can delete WdFilter.sys and MsMpEng.exe even with Tamper Protection active</li>
<li>Demonstrated at Black Hat USA 2026 and DEF CON 34 on August 20, 2026</li>
<li>No real-world attacks found to date</li>
</ul>
