### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Elementor Pro WordPress plugin flaw enables remote code execution
A critical remote code execution vulnerability (CVE-2026-32475, CVSS 9.0) in Elementor Pro allows unauthenticated attackers to upload and execute PHP files through the Forms module's File Upload field. The flaw affects all versions through 4.2.1 and requires only a published page containing a Form widget with File Upload. Patch version 4.2.2 released August 19, 2026.

<ul class="takeaways">
<li>CVE-2026-32475, CVSS score 9.0 (critical)</li>
<li>Affects all versions prior to and including 4.2.1</li>
<li>Unauthenticated remote code execution via File Upload field in Forms module</li>
<li>Patch 4.2.2 released August 19, 2026</li>
<li>Requires only default File Upload field (no special settings needed)</li>
<li>Discovery: July 16, 2026 via Patchstack Bug Bounty Program</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Federal agencies warn of active AI-generated attacks on critical infrastructure controllers
Five U.S. federal agencies (NSA, CISA, FBI, DOE, EPA) warned August 19, 2026, that threat actors are actively using AI-generated code to compromise critical infrastructure control systems. Attackers target internet-exposed Siemens S7 Series programmable logic controllers at water, manufacturing, and energy facilities. Iranian cyber operatives are suspected, including a late July 2026 cyberattack disrupting 30+ community water systems across 12+ states.

<ul class="takeaways">
<li>Joint warning August 19, 2026 from NSA, CISA, FBI, DOE, EPA</li>
<li>Threat actors use AI-generated code with open-source automation libraries (snap7.dll/python-snap7)</li>
<li>Target: Internet-exposed Siemens S7 Series PLCs at water, manufacturing, energy facilities</li>
<li>July 2026 attack disrupted 30+ water systems across 12+ states</li>
<li>Iranian cyber operatives suspected involvement</li>
<li>State-sponsored adversaries using AI for code checks and scripting to scale operations</li>
<li>Joint advisory issued August 20, 2026 by NSA, CISA, FBI, EPA, DOE</li>
<li>Threat actors using AI to develop exploitation scripts</li>
<li>Targets include Siemens S7-200, S7-300, S7-400, S7-1200, S7-1500 PLCs</li>
<li>Affected sectors: energy, manufacturing, water, food, agriculture, chemical, commercial</li>
<li>AI scripts reduce expertise and development time for ICS attacks</li>
</ul>
