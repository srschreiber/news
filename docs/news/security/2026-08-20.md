### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> NASA AIT-GUI security flaws allow unauthenticated spacecraft command injection
Security researchers disclosed a chain of flaws in NASA's AIT-GUI operator console allowing unauthenticated attackers to issue arbitrary commands to spacecraft and instrument systems. The vulnerabilities stem from hardcoded binding, missing authentication on state-changing routes, and unvalidated input handling; AIT-GUI 2.5.2 released August 12, 2026, addresses these issues.

<ul class="takeaways">
<li>Vulnerability chain GHSA-p9r8-2q67-fp86 CVSS 9.4; affects AIT-GUI 2.5.1 and earlier</li>
<li>Flaws allow unauthenticated remote arbitrary spacecraft and instrument commands</li>
<li>Web server binds to 0.0.0.0:8080 by default with no authentication on state-changing routes</li>
<li>Patch released August 12, 2026 (AIT-GUI 2.5.2); advisory published August 13, 2026</li>
</ul>
