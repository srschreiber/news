### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Microsoft's Agent Framework PyPI Package Compromised with Credential Stealer
On November 17, 2026, attackers compromised Microsoft's agent-framework package on PyPI, releasing malicious versions 1.26.1 and 1.26.2 roughly 33 minutes apart. The package, designed for developing AI agents and multi-agent applications, has approximately 190,000 downloads per month. Both malicious versions were quarantined on PyPI; version 1.26.0 remains the latest clean release. The malware retained legitimate framework components while introducing code to steal credentials. It executes automatically via a Python startup mechanism whenever the Python interpreter starts, even if the application does not explicitly import the compromised package. Targets include secrets in environment variables and configuration files, credentials from other running processes, Azure managed identity tokens, and Azure DevOps authentication tokens. Version 1.26.2 expanded functionality to steal GitHub Actions credentials. The malicious versions contained only built packages, unlike legitimate releases which included both built and source distributions. No corresponding malicious code was found in Microsoft's main source repository. The method used to publish the packages remains unknown. Microsoft acknowledged the incident and confirmed an investigation was underway.

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Perforce Puppet RCE Vulnerability CVE-2026-115731 Actively Exploited
A critical remote code execution vulnerability in Perforce Puppet tracked as CVE-2026-115731 (CVSS 9.4) is being actively exploited. The vulnerability is a deserialization of untrusted data issue in the report processing of Puppet Enterprise and Puppet Core that allows clients holding a certificate signed by the Puppet certificate authority to send reports with malicious payloads executed on the server with service user permissions. A successful attack could expose the server's certificate-signing key, allow issuance of trusted certificates, and enable changes to software and configuration delivered to managed systems. The flaw was patched on November 3 alongside CVE-2026-115732. Patched versions include Puppet Enterprise and Puppet Enterprise Advanced 2026.0.1, 2025.12.1, and 2023.8.13, and Puppet Core 9.1.3 and 8.22.2. The vulnerability was flagged as exploited on November 4. The US cybersecurity agency CISA added CVE-2026-115731 to its Known Exploited Vulnerabilities catalog on November 17, urging federal agencies to patch within two weeks per BOD 26-04. The vulnerability also affects OpenVox configuration management platform. Administrators are advised to disable auto-signing of certificate requests and enforce strong validation.

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Russian APT exploits stolen identities to breach US organization after prior compromise
Russia-linked APT Star Blizzard (also tracked as Callisto, Cold Relic, Cold River, UNC4057, and Gossamer Bear) breached a US organization by impersonating an employee of another US organization it had previously compromised. The first organization was hit in late 2025 using compromised credentials of a super admin account; Star Blizzard exploited MFA push notification fatigue to register a device to the victim's tenant. During that initial intrusion, the group downloaded the organization's entire cloud storage drive, accessed the admin console to fingerprint defenses and remove evidence, exported full employee lists, launched a domain-wide export, and exfiltrated emails and targeted cloud drive documents. The group used passkeys, rogue MFA devices, and MFA backup codes to maintain persistent access for several months. Star Blizzard then weaponized contact and relationship information obtained during the earlier intrusion to select and phish a separate US target by impersonating an employee of the first breached organization. Star Blizzard is formally associated by the US with Russia's FSB intelligence service and has been active for over a decade, known for targeting high-value victims including government officials, defense contractors, and NGOs across Europe and North America.

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> New TPM Attack Breaks Windows Hello and BitLocker PINs
Researchers at Technische Universität Berlin discovered a hardware-level vulnerability affecting TPM (Trusted Platform Module) lockout mechanisms on AMD-based PCs and some Intel PCs. By physically opening the PC case and accessing the mainboard's flash chip, attackers can reset the TPM lockout counter that protects Windows Hello and BitLocker PINs from brute-force guessing. In laboratory tests, researchers cracked a four-digit Windows Hello PIN in 57 minutes (236 attempts) and a six-digit BitLocker PIN in 6 minutes 55 seconds (236 attempts). Without the lockout mechanism, worst-case attack times drop dramatically: a four-digit Hello PIN from 69 days to 40 hours; a six-digit BitLocker PIN from 19 years to 20 days. The vulnerability stems from two separate weaknesses depending on hardware configuration. On AMD PCs using RPMC (Replay Protected Monotonic Counter) counters, the processor firmware fails to verify that counters actually increased, allowing an interposer board to block updates and report false success. On systems with Winbond flash chips, a voltage glitch attack can extract the secret key that signs counter values in approximately one second, enabling forgery of any counter value. AMD confirmed the processor firmware flaw and plans fixes for most affected chips between November 2026 and February 2027. Microsoft's documented lockout policy locks the TPM after 32 wrong PIN attempts with a 10-minute delay between failures, but this protection is bypassed by resetting the counter. Researchers advised temporarily adding at least two digits to Windows Hello and BitLocker PINs as mitigation.
