### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> WSO2 API Manager JWT Bypass Vulnerability Under Active Exploitation
CVE-2026-5430, a critical JWT authentication bypass vulnerability in WSO2 API Manager and related products, is under active exploitation as of September 13, 2026. The flaw allows attackers to forge admin tokens by using unsupported cryptographic algorithms, enabling full account takeover and access to sensitive credentials.

<li>Active exploitation detected September 13, 2026</li>
