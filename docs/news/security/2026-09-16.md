### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> WSO2 API Manager JWT Bypass Vulnerability Under Active Exploitation
CVE-2026-5430, a critical JWT authentication bypass vulnerability in WSO2 API Manager and related products, is under active exploitation as of September 13, 2026. The flaw allows attackers to forge admin tokens by using unsupported cryptographic algorithms, enabling full account takeover and access to sensitive credentials.

<ul class="takeaways">
<li>CVSS score 9.8/10.0</li>
<li>Affects API Manager 4.1.0–4.6.0, API Control Plane 4.5.0–4.6.0, Traffic Manager 4.5.0–4.6.0, Universal Gateway 4.5.0–4.6.0</li>
<li>Active exploitation detected September 13, 2026</li>
<li>Patches released May 2026; community fixes available via GitHub</li>
<li>Attackers can access API credentials, consumer keys, and secrets for registered applications</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Parallels Desktop privilege escalation flaw affects Mac users; Intel Macs unable to install fix
Parallels Desktop for Mac contains a privilege escalation vulnerability (CVE-2026-90894) allowing non-admin users to execute code as root through a flaw in the prl_disp_service background service. The fix is available in Parallels Desktop 27 but Intel-based Mac systems cannot install this version, leaving them unable to remediate the vulnerability.

<ul class="takeaways">
<li>CVE-2026-90894 privilege escalation vulnerability</li>
<li>CVSS severity 7.8</li>
<li>Affects Parallels Desktop 26.4.0 build 57513</li>
<li>Intel-based Macs cannot install Parallels Desktop 27 (the patched version)</li>
<li>Exploits improper command parsing via double quote in folder name</li>
<li>Requires code already running as normal user, not exploitable over network</li>
</ul>
