### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Microsoft Azure API Management flaw exploited to steal customer credentials
A vulnerability in Microsoft Azure API Management Classic tier was exploited to steal stored API credentials including client secrets, subscription keys, and tokens. Norwegian authorities linked attacks to energy sector targets including Equinor and Skagerak Energy. The flaw affected only the classic version, not APIM v2.

<ul class="takeaways">
<li>Vulnerability limited to Azure APIM Classic tier, not v2</li>
<li>Stolen credentials: client secrets, subscription keys, management API tokens</li>
<li>Attacks targeted Norwegian energy companies Equinor and Skagerak Energy</li>
<li>NSM advised treating all APIM-stored credentials as compromised</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Chinese threat actor Webworm deploys modified SoftEther VPN for covert remote access
China-aligned threat actor Webworm deployed a modified open-source SoftEther VPN tool (version 4.44) disguised as 'NtMonitor VPN' to establish covert remote access while evading detection. Key modifications included replacing HTTP endpoints, changing protocol watermarks, and encrypting configuration files.

<ul class="takeaways">
<li>Modified SoftEther VPN v4.44 rebranded as &#x27;NtMonitor VPN&#x27;</li>
<li>HTTP endpoints changed to innocuous &#x27;/update/alive.cgi&#x27; and &#x27;/update/picture.cgi&#x27;</li>
<li>Configuration file encrypted with custom algorithm</li>
<li>Binary size increased ~1.5 MB by embedding hamcore.se2 resource archive</li>
</ul>
