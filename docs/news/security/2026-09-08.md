### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Adobe patches critical Commerce and Magento vulnerability exploited for Rust backdoor deployment
Adobe released emergency patches for a maximum-severity zero-day flaw in Adobe Commerce and Magento Open Source (CVE-2026-75650) that was actively exploited to install Rust backdoors and PHP web shells.

<ul class="takeaways">
<li>Vulnerability affects all current Magento versions including 2.4.9 and Adobe Commerce 2.4.6-p15 with July/August 2026 patches</li>
<li>Active attacks began September 4, 2026; at least two stores confirmed breached</li>
<li>Adobe has not published CVE, advisory, or patch as of September 6; next security release scheduled September 8</li>
<li>Sansec&#x27;s interim workaround: disable GraphQL (breaks headless and PWA storefronts)</li>
<li>Researcher-reported vulnerability name: StyleSmuggler</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> BengalSEO campaign poisons Bing search results with malware and scams
The BengalSEO campaign, operating from Rajasthan, India since at least 2015, poisons Bing search results using black hat SEO techniques to deliver malware and tech support scams. The operation uses a sophisticated traffic distribution system and deploys custom malware called MayaBot, which includes a cryptocurrency miner.

<ul class="takeaways">
<li>Campaign run by WeConnect Solutions LLC and Garage2Global in Rajasthan, India</li>
<li>Operates since at least 2015, discovered March 2026</li>
<li>Uses black hat SEO: backlinks, DOM injection, keyword stuffing, forum spam</li>
<li>Custom MayaBot malware deployed since 2022 with command-and-control and XMRig miner</li>
<li>Employs Matomo analytics and domain redirector chains for traffic routing</li>
</ul>
