### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Rackspace Shuts Down Spot Cloud Platform After Security Breach
Rackspace announced shutdown of its Spot cloud platform following a November 18 security breach discovered after a customer report. Unauthorized actors accessed Kubernetes clusters on November 17, deploying pods and accessing secrets containing authentication tokens, API keys, and passwords. December 8 is the migration deadline.

<ul class="takeaways">
<li>Breach date: November 17, 2026 (12:20 a.m.–10 p.m. UTC)</li>
<li>Discovery date: November 18 via customer report</li>
<li>Access method: compromised credentials</li>
<li>Exposed: Kubernetes clusters, secrets, auth tokens, API keys, passwords</li>
<li>Migration deadline: December 8, 2026</li>
<li>Response: revoked sessions, rotated keys, enhanced monitoring, provided indicators of compromise</li>
</ul>
