### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> CIA cyber breach exposes vulnerabilities in US intelligence infrastructure
The CIA and at least two other US intelligence agencies—the National Geospatial-Intelligence Agency (NGA) and the Office of the Director of National Intelligence (ODNI)—suffered a cyber intrusion in November 2026 that exposed unclassified information. The breach targeted an open-source intelligence analysis system used to identify insights in publicly available and other unclassified material. Classified data was not affected. Investigators believe hackers used an artificial intelligence-based cybersecurity tool called Artex, released publicly in July by a Chinese engineer and subsequently adapted for malicious purposes. The tool has been linked by cybersecurity researchers to dozens of attacks on businesses worldwide, including in Japan and South Korea. Initial indications, including the use of Artex, suggest a possible Chinese connection, though the identity of those responsible has not been established. The breach coincides with a broader series of recent cybersecurity incidents affecting multiple US government agencies in November 2026, including the Treasury Department's Financial Crimes Enforcement Network (FinCEN), the FBI, and the USDA. An official from ODNI stated the incident had not disrupted critical capabilities and that the issue had been resolved.

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Threat actors actively exploit GeoServer security flaws for unauthenticated remote code execution
Threat actors are actively exploiting two newly patched GeoServer vulnerabilities (CVE-2026-120705 and CVE-2026-129243) disclosed on November 24, 2026, to achieve unauthenticated remote code execution. CVE-2026-120705 (CVSS 8.6) is an arbitrary file read vulnerability in the WFS module that allows attackers to access local text files or fetch HTTP/HTTPS URLs via unauthenticated requests. CVE-2026-129243 (CVSS 8.8) is an incorrect authorization flaw allowing unauthenticated invocation of protected OWS operations. Security researchers watchTowr reported that attackers sent error-based exploit probes using stored queries to validate server vulnerability. Eye Security discovered CVE-2026-120705 and identified it can be chained with two additional flaws—CVE-2026-129245 (CVSS 9.2, hard-coded signing key in "remember me" functionality) and CVE-2026-120704 (CVSS 7.2, improper code generation control)—to form a complete unauthenticated RCE attack chain. The chain exploits CVE-2026-120705 to extract users.xml and security configuration files containing password hashes and signing keys, then uses CVE-2026-129245 to forge administrator authentication cookies, and finally leverages CVE-2026-120704 to execute arbitrary code via JDBC configuration. Patches for all affected versions (3.0.2, 2.28.6, and 2.27.7 of GeoServer and related components) were released on November 24, 2026.

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Drupal RCE Vulnerability Exploited in Wild, Added to CISA's Known Exploited List
CISA added CVE-2026-132165, a critical remote code execution vulnerability in Drupal, to its Known Exploited Vulnerabilities catalog on November 25, 2026, with a remediation deadline of November 27, 2026 for federal agencies. The flaw, dubbed Fail2Install (CVSS 9.8), affects Drupal core and allows unauthenticated attackers to take over existing sites or execute arbitrary code via the Drupal installer (install.php). The vulnerability impacts Drupal versions 8.9, 9, 10, and 11 across four deployment combinations: Apache with PostgreSQL, Apache with MySQL, PHP-FPM with PostgreSQL, and PHP-FPM with MySQL. According to Searchlight Cyber analysis, the attack exploits the installer's checks for existing installations by exhausting server resources (EMFILE, database connection exhaustion, or TCP source-port exhaustion) to trick Drupal into entering its installation process. The attacker can then create an administrator account and execute arbitrary PHP code by selecting a path ending in .php under the document root during installation, causing the installer to create an SQLite database file with a PHP extension containing injected payload code.

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Drupal RCE Vulnerability Actively Exploited
Drupal's security team confirmed a critical remote code execution vulnerability in Drupal Commerce Core is being actively exploited in the wild. The vulnerability is tracked as CVE-2026-118539 with a CVSS score of 6.5 and is classified as a missing authorization flaw affecting Commerce Core versions 0.0.0 to 2.41 and 3.0.0 to 3.3.13. The flaw allows attackers to bypass access controls on certain routes and entity fields, potentially causing financial impact to vendors. Drupal has recommended users update to Commerce Core 3.3.13 for version 3.x users or Commerce Core 8.x-2.41 for earlier versions. The vulnerability was reported by researchers Dan Puccetti, Marcus Johansson, and Robert Snyder. Active exploitation in the wild has been confirmed, though specific details about the nature or extent of the campaign were not provided.
