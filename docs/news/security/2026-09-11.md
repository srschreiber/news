### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> GitLab Vulnerability Exploited One Day After Public Disclosure
A critical-severity GitLab path traversal vulnerability (CVE-2026-85706, CVSS 10/10) allowing unauthenticated file access was exploited in the wild within one day of public disclosure on September 11, 2026. The flaw affects multiple GitLab versions and was observed by WatchTowr with mass exploitation expected imminently.

<ul class="takeaways">
<li>CVE-2026-85706, CVSS 10/10 path traversal enabling unauthenticated arbitrary file read</li>
<li>Exploited within 24 hours of public disclosure on September 11, 2026</li>
<li>Affects GitLab CE/EE versions 18.7, 19.2, 19.3 (multiple minor versions)</li>
<li>Patches also address CVE-2026-87719 (CVSS 9.9/10) and 16 other vulnerabilities</li>
<li>Attackers target &#x27;/api/v4/projects/{id}/repository/commits/&#x27; URIs with &#x27;file.path&#x27; parameters</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> China-linked hackers exploited Sogou Input Method flaw to deploy GRAYRABBIT backdoor
UNC3569, a China-linked hacking group, exploited a Sogou Input Method vulnerability to deploy the GRAYRABBIT backdoor. Sogou is the dominant Chinese character input tool, used by over 455 million monthly users (approximately 70% of Chinese input-method users). The attack leveraged a disabled sandbox in an embedded outdated Chromium browser.

<ul class="takeaways">
<li>Sogou Input Method: 455+ million monthly users across Windows, Android, iOS; ~70% of Chinese input-method market share</li>
<li>Attack vector: malicious sgbiz: protocol link passed to biz_helper.exe without argument validation</li>
<li>Exploit chain used browser rendering of malicious page via Sogou&#x27;s skin store; Chromium version 80 (from 2020) had sandbox and same-origin policy disabled</li>
<li>Tencent patched vulnerability April 2026 but only blocked attack vector, not underlying browser engine issues</li>
</ul>

<li>GTG-10007: Chinese group including Hunan university students targeting 50 organizations across 8 sectors in Americas, Europe, Middle East, Southeast Asia</li>
