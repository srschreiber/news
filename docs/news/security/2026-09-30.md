### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Pentagon Personnel Agency Suffers Data Breach Affecting 3 Million People
The U.S. Defense Manpower Data Center (DMDC) disclosed a nine-month unauthorized access to a file-sharing server discovered in July 2026, exposing personal information of 2.76 million living individuals and 294,000 deceased persons. The breach resulted from an unpatched vulnerability that allowed attackers to access sensitive military and civilian personnel records from October 2025 through mid-July 2026.

<ul class="takeaways">
<li>Unauthorized access to DMDC file-sharing server lasted approximately 9 months (October 2025–July 2026)</li>
<li>Exposed data includes Social Security numbers, names, dates of birth, contact details, and military occupational specialties for 2.76 million living individuals and 294,000 deceased individuals</li>
<li>Vulnerability was discovered on July 16, 2026, and patched immediately; system was restored</li>
<li>No evidence of misuse of accessed information at time of disclosure</li>
<li>No known cybercrime group has claimed responsibility for the attack</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Cisco warns of critical zero-day in SD-WAN Manager under active exploitation
Cisco disclosed CVE-2026-76504, a critical authentication bypass in Catalyst SD-WAN Manager allowing unauthenticated remote access to the API with admin privileges via URI encoding mishandling. Active exploitation was confirmed in September 2026 after a support case exposed the flaw.

<ul class="takeaways">
<li>CVE-2026-76504: CVSS 9.8, authentication bypass in SD-WAN Manager API</li>
<li>Allows admin-level access without login credentials via crafted HTTP request</li>
<li>Active exploitation confirmed September 2026</li>
<li>Flaw in API endpoint login session handling</li>
<li>Fixed releases: 20.9.10.1, 20.12.8.2, 20.15.6.1, 20.18.4.1, 26.1.2.1, 26.2.1</li>
<li>Cloud-hosted environments already protected; no workaround exists</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> CISA warns of critical pre-auth RCE vulnerability in MikroTik RouterOS
CISA added CVE-2026-67279, a critical pre-authentication remote code execution flaw in MikroTik RouterOS, to its Known Exploited Vulnerabilities catalog on September 26, 2026. Chained with CVE-2026-86060, the vulnerabilities enable full administrative access without password authentication.

<ul class="takeaways">
<li>CVE-2026-67279: CVSS 6.9, pre-auth RCE in RouterOS</li>
<li>Improper enforcement of behavioral workflow vulnerability</li>
<li>Combined with CVE-2026-86060 (argument injection) = full admin access without password</li>
<li>Exploit named &#x27;MikroTrick&#x27;; confirmed reproducible on RouterOS 7.x</li>
<li>CVE-2026-86060 added to KEV September 11, 2026</li>
<li>Federal agencies required to patch by September 28, 2026</li>
</ul>
