### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> GitLab patches critical CVSS 10.0 flaw allowing unauthenticated code execution
GitLab released patches for CVE-2026-97229, a CVSS 10.0 maximum-severity integer overflow vulnerability in CI/CD configuration handling that allows unauthenticated users to execute arbitrary code via malicious regular expressions. The company also patched three high-severity flaws affecting authentication, authorization, and cache security.

<ul class="takeaways">
<li>CVE-2026-97229: CVSS 10.0 integer overflow in CI/CD configuration</li>
<li>Allows unauthenticated arbitrary code execution on GitLab server</li>
<li>Affected versions: 19.2 before 19.2.8, 19.3 before 19.3.5, 19.4 before 19.4.2</li>
<li>CVE-2026-92883 (CVSS 8.7): XSS allowing authenticated code execution</li>
<li>CVE-2026-16301 (CVSS 8.5): improper authorization in downstream pipelines</li>
<li>CVE-2026-14814 (CVSS 8.2): regex allowing cache poisoning and environment variable exposure</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> $86 Million Crypto Heist Attributed to Hardware Implant in Ledger Signer Devices
A hardware implant inserted under Ledger device screens by someone in the Southeast Asia distribution chain stole at least $86 million in cryptocurrency. The soldered circuit board read 24-word recovery phrases during setup and transmitted them via LTE eSIM to attackers; all confirmed losses involved signers sold through reseller CryptoBilis.

<ul class="takeaways">
<li>Implant soldered onto signer circuit board under screen</li>
<li>Intercepted 24-word recovery phrase during device setup</li>
<li>Transmitted credentials over LTE using provisioned eSIM</li>
<li>At least $86 million stolen; actual losses may exceed this figure</li>
<li>All confirmed losses from CryptoBilis reseller in Southeast Asia</li>
<li>Disclosure October 9, 2026; Ledger confirmed October 13</li>
</ul>
