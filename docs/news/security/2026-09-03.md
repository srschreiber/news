### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> CISA adds seven actively exploited vulnerabilities to known threats catalog
CISA added seven actively exploited vulnerabilities to its Known Exploited Vulnerabilities catalog on September 3, including two CVSS 10.0 flaws in SonicWall and Kestra. Threat actors have deployed reverse shells, minted admin tokens, and chained vulnerabilities for remote code execution and ransomware deployment.

<ul class="takeaways">
<li>CVE-2026-83548 (CVSS 10.0): SonicWall server-side request forgery, unauthenticated remote access</li>
<li>CVE-2026-9586 (CVSS 9.3): Sangoma Switchvox SQL injection, remote code execution</li>
<li>CVE-2026-82329 (CVSS 9.8): JFrog Artifactory improper authentication, unauthenticated admin access</li>
<li>CVE-2026-49869 (CVSS 10.0): Kestra OS command injection, unauthenticated workflow execution</li>
<li>CVE-2026-48710 (CVSS 6.5) chained with CVE-2026-42271; Qilin ransomware actors exploiting actively</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> NSO Pegasus spyware infects Serbian activist's iPhone via iMessage
