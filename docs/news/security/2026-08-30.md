### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Chrome and Edge extensions deploy cryptocurrency and data-stealing malware framework
Multiple browser extensions for Chrome and Edge delivered a malware framework that stole cryptocurrency, sensitive data, and browser history while injecting ClickFix phishing lures.

<ul class="takeaways">
<li>18 Chrome extensions, 1 Edge extension identified stealing wallet credentials</li>
<li>14 extensions created by threat actor, 5 purchased from previous owners</li>
<li>Campaign activity dates back to February 2024; distributed via Chrome Web Store</li>
<li>Threat actor created fake websites impersonating crypto utilities, VPNs, and banking services</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> TerminalFix malware uses fake Cloudflare CAPTCHAs to deploy reverse-tunnel backdoor
Microsoft disclosed TerminalFix, a ClickFix malware variant that deceives users into executing malicious PowerShell commands via fake Cloudflare CAPTCHA pages. The attack deploys a reverse-tunnel backdoor that grants attackers persistent network access to reach internal systems and conduct reconnaissance, lateral movement, and data exfiltration.

<ul class="takeaways">
<li>Malicious command runs LockScreenContentServer.exe and loads rogue dui70.dll via DLL sideloading</li>
<li>PNG-embedded payloads retrieved from bestsocialmedianewspapper[.]com or offlineupdater[.]com</li>
<li>Python reverse-tunnel C2 (client.py) tunnels traffic to gitnow[.]dev:443 via encrypted WebSocket</li>
<li>Establishes persistence via Registry Run keys and scheduled tasks</li>
<li>Performs domain reconnaissance, admin enumeration, and network topology mapping</li>
<li>Enables C2 server to proxy traffic to internal systems accessible from victim network</li>
</ul>
