### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> AI-Discovered Linux Kernel Vulnerability Allows Local Root Access and VM Escape
A critical Linux kernel vulnerability (CVE-2026-74580, 'Vghost') discovered by AI analysis allows local users to escalate privileges to root across nearly a decade of kernel versions (4.11–7.2-rc4). In certain virtualization setups, untrusted guest VMs can escape to the host hypervisor. The flaw stems from a stale cache of memory mappings dating to 2017, with a second error in 2020.

<ul class="takeaways">
<li>Vghost affects Linux 4.11 through 7.2-rc4—nearly 10 years of releases</li>
<li>Allows local root escalation and potential VM-to-host escape in specific configurations</li>
<li>Root cause: vhost fails to invalidate cached memory mappings when ring reconfigured</li>
<li>Flaw originated 2017 (cache added), compounded 2020 (bounds check removed)</li>
<li>Tencent published proof-of-concept October 12; Ubuntu, RHEL, Amazon Linux, Azure Linux, Oracle Linux vulnerable; world-readable vhost device on 4 of 5 distros tested</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Researchers Break Into Windows SmartScreen Enclave via Write Vulnerability and Timing Bug
Doyensec researchers executed arbitrary code inside a Windows VBS enclave protecting SmartScreen using a four-byte write flaw and timing side-channel attack. Microsoft patched the vulnerability (CVE-2026-83498, CVSS 7.8) in September; Doyensec published research on October 13, over a month after the fix.

<ul class="takeaways">
<li>Four-byte write flaw in SFAPE.dll Initialize function; timing side-channel in second function</li>
<li>Exploits required local access and low-level privileges; cannot be exploited remotely</li>
<li>Enclave stores hashed Windows sign-in passwords to detect unsafe credential entry</li>
<li>Microsoft patched September 8 before public disclosure</li>
<li>Not exploited in wild; Microsoft rated CVE-2026-83498 Critical (CVSS 7.8)</li>
</ul>
