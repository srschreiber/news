## Security Breach

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> 1Password suffers data breach via compromised GitHub account
1Password suffered a data breach on November 19 when an attacker compromised an employee's GitHub account, accessed source code, injected malicious code into backend services, and obtained infrastructure secrets. Customer vaults, passwords, and Secret Keys were not accessed. 1Password rotated credentials and tightened system controls.

<ul class="takeaways">
<li>Breach occurred November 19 via compromised employee GitHub account</li>
<li>Attacker accessed source code, injected malicious code into backend, accessed CI/CD secrets</li>
<li>Exposed data: names, emails, account/user IDs, creation/sign-in dates, public keys, SRP parameters</li>
<li>Customer vault contents, account passwords, Secret Keys not compromised</li>
<li>Invitation/recovery code length increased from 6 to 10 alphanumeric characters</li>
<li>Breach discovered November 19, disclosed November 26</li>
<li>Attacker accessed customer names, emails, account creation/sign-in dates, public keys</li>
<li>Vault data, passwords, encryption keys, recovery keys, Secret Keys not compromised</li>
<li>Revoked stolen token, disabled GitHub account, deployed new detection tools</li>
<li>Users advised to watch for phishing via compromised email addresses</li>
</ul>
