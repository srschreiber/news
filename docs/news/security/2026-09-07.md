### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> N-able releases fourth hotfix in five weeks for critical N-central RCE vulnerability
N-able released its fourth hotfix in five weeks for CVE-2026-86218, an unauthenticated remote code execution vulnerability in N-central affecting all builds before version 2026.3.1.14. N-able's communications conflict on exploitation status, with the incident notice stating the flaw "has been observed being exploited in the wild" while release notes claim no production exploitation confirmations.

<ul class="takeaways">
<li>CVE-2026-86218: unauthenticated remote code execution, CVSS 10.0</li>
<li>Static code injection flaw (CWE-96) affecting all N-central builds before 2026.3.1.14</li>
<li>Fourth hotfix in five weeks; Hotfix 3 released eight hours before Hotfix 4</li>
<li>Hosted N-central instances already patched; on-premises customers must upgrade immediately</li>
<li>Huntress recommends IP allowlisting, VPN restriction, or taking servers offline until patching</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Hackers exploit MikroTik RouterOS vulnerabilities to hijack exposed routers
Attackers are exploiting a chain of two recently disclosed MikroTik RouterOS flaws to take control of routers with SSH services exposed to the internet.

<ul class="takeaways">
<li>Vulnerability termed &#x27;MikroTrick&#x27; involves two unidentified flaws bypassing SSH authentication</li>
<li>Affected RouterOS: 6.0.0–6.49.20, 7.0.0–7.23.3, 7.24.0–7.24.1</li>
<li>Patches released: 6.49.21, 7.23.5, 7.24.2</li>
<li>Attacks documented since at least September 2, 2026</li>
<li>Post-compromise indicators: Flagged status warnings, unknown accounts, ssh:-2@ pattern in logs</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> JSCeal malware bypasses Google authentication using stolen session cookies
JSCeal, a sophisticated JavaScript malware, bypasses Google authentication using stolen session cookies and performs credential harvesting and surveillance. Distributed via malvertising campaigns using fake cryptocurrency trading sites, it has been actively targeting retail traders and cryptocurrency investors across 12 countries in multiple languages since late 2024.

<ul class="takeaways">
<li>First documented by Check Point Research in July 2025</li>
<li>Distributed via malvertising with fake TradingView installers on Facebook and Google ads</li>
<li>Related SourTrade campaign disclosed by Confiant in August 2026, active since late 2024</li>
<li>Targets retail traders and cryptocurrency investors across 12 countries in 25 languages</li>
<li>Capabilities: enumerate installed browsers, query saved secrets, cookies, and OAuth tokens</li>
<li>Obfuscation uses javascript-obfuscator with RC4-protected strings and control-flow flattening</li>
</ul>
