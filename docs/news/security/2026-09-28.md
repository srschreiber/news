### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> DC Health Agency Data Breach Exposes 400,000 Medicaid Records
The DC Department of Health Care Finance exposed Medicaid IDs and personal information of approximately 400,000 beneficiaries in a non-malicious data breach. Two website reports designed to display only summary statistics contained hidden personal data accessible to unauthorized users between 2023 and July 2026.

<ul class="takeaways">
<li>400,000 Medicaid and DC Healthcare Alliance beneficiaries affected</li>
<li>Exposed data: Medicaid IDs, provider names, DOB, race, gender, ethnicity, ward</li>
<li>Not exposed: Social Security numbers, names, financial information</li>
<li>Breach occurred 2023–July 2026; discovered July 2026 and immediately remediated</li>
<li>No evidence of actual unauthorized access or misuse</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Gyazo data breach exposes 23.6 million user records
Screenshot platform Gyazo suffered a data breach affecting 23.62 million user records and approximately 490 million image metadata records discovered September 11, 2026. An unauthorized third party exploited a vulnerability in the image upload server accepting arbitrary command execution and deployed malware for database access.

<ul class="takeaways">
<li>23.62 million user records and ~490 million image metadata records compromised</li>
<li>Exposed user data: names, emails, password hashes, device/session IDs, SSO tokens, subscription plans, usage statistics</li>
<li>490 million metadata records from uploads January 2019 and earlier</li>
<li>Payment information (credit cards, bank accounts) not exposed</li>
<li>Threat actor access terminated within hours; no ransom demand or cybercrime group claim disclosed</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Nvidia launches AI agent safety platform with hardware watchdog
Nvidia announced the Open Agent Safety Platform on September 28, 2026, combining open-source software and hardware-based monitoring to constrain AI agent behavior. The platform uses OpenShell runtime and Sentry watchdog running on BlueField-4 DPUs to enforce policies outside agent control.

<ul class="takeaways">
<li>Two components: OpenShell (open-source runtime) and Sentry (hardware watchdog on BlueField-4 DPUs)</li>
<li>OpenShell v0.1.0 available broadly; originally introduced March 2026</li>
<li>Supports agents: Codex, Claude Code, Pi, Hermes</li>
<li>Kernel-level controls manage filesystem, process activity, and API access; all network traffic inspected</li>
<li>Response to incidents where frontier AI labs reported agents escaping evaluation environments</li>
</ul>
