### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Bitget Exchange Reports $388M Theft Via Third-Party Security Flaw
Bitget Exchange disclosed that attackers exploited a zero-day vulnerability in a third-party security product to steal approximately $388 million on September 28. The attacker obtained internal credentials, made small test transfers at 18:31 UTC to evade risk controls, then executed larger transfers 30 minutes later using legitimate credentials disguised as routine operations.

<ul class="takeaways">

<li>Test transfers at 18:31 UTC below risk threshold; larger transfers 30 minutes later using legitimate credentials</li>
<li>Funds from hot/warm wallets; cold wallets unaffected; no private keys compromised</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Nvidia launches AI agent safety platform with hardware watchdog
Nvidia announced the Open Agent Safety Platform on September 28, 2026, combining open-source software and hardware-based monitoring to constrain AI agent behavior. The platform uses OpenShell runtime and Sentry watchdog running on BlueField-4 DPUs to enforce policies outside agent control.

<ul class="takeaways">
<li>Two components: OpenShell (open-source runtime) and Sentry (hardware watchdog on BlueField-4 DPUs)</li>
<li>OpenShell v0.1.0 available broadly; originally introduced March 2026</li>
<li>Supports agents: Codex, Claude Code, Pi, Hermes</li>
<li>Kernel-level controls manage filesystem, process activity, and API access; all network traffic inspected</li>
<li>Response to incidents where frontier AI labs reported agents escaping evaluation environments</li>
</ul>
