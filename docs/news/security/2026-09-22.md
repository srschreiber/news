### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Malicious NPM Package indexed-btree Concealed Loader in Runtime Code
A malicious npm package named indexed-btree, uploaded June 18, 2026, concealed malware within runtime code rather than lifecycle scripts to evade npm's security controls. The package accumulated millions of downloads before removal and generated approximately €230,933.57 in cryptocurrency, with at least nine additional compromised packages tied to the same operation.

<ul class="takeaways">
<li>Uploaded June 18, 2026; accumulated millions of downloads</li>
<li>Malware hidden in BTree.prototype.set() method to evade lifecycle script restrictions</li>
<li>Generated €230,933.57 (~109 ETH) for threat actor</li>
<li>At least 9 additional compromised packages: ordered-kv-index, btree-leaderboard, priority-slot-queue, btree-range-store, btree-core, btree-time-index, btree-lru-cache, neighbor-key-map, sliding-score-window</li>
<li>Used EtherHiding technique via Sepolia testnet smart contract for payload delivery</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Windows Defender zero-day blocks antivirus updates
A June 2026 zero-day in Microsoft Defender (CVE-2026-50656, RoguePlanet) allows remote attackers to gain administrative control of Windows 10/11 machines. Microsoft's July patch introduced a memory leak enabling disk exhaustion via unlimited Zone.Identifier caching, preventing normal antivirus operation.

<ul class="takeaways">
<li>CVE-2026-50656 (RoguePlanet) disclosed June 2026 with public exploit code</li>
<li>Microsoft patched via Malware Protection Engine update July 9, 2026</li>
<li>Patch defense-in-depth introduces 8-byte memory leak in mpengine.dll when opening files</li>
<li>SpyNet cloud caching of Zone.Identifier alternative data streams has no size limits, allowing attackers to exhaust disk space</li>
</ul>
