### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> 153GB of Stolen Credentials Surface From LiteLLM Supply Chain Breach
A 153GB archive of credentials stolen in a supply chain attack on LiteLLM has surfaced, compromising 2,488 corporate domains including AWS, Samsung, Cisco, Nvidia, and Microsoft. The breach originated from a March 2026 compromise of Trivy, a vulnerability scanner, which TeamPCP weaponized to inject malicious code into LiteLLM versions 1.82.7 and 1.82.8 published to PyPI. Exposed secrets include AWS keys, Salesforce tokens, Slack signing secrets, and AI provider API credentials.

<ul class="takeaways">
<li>153GB archive with 433,909 files and 118,829 CI runner dumps</li>
<li>2,488 corporate domains affected including AWS, Samsung, Cisco, Salesforce, Nvidia, Microsoft, FedEx</li>
<li>Breach timeline: Trivy compromised March 19, malicious LiteLLM versions released March 24, 40-minute exposure window</li>
<li>Compromised credentials: AWS secret keys, Salesforce client secrets, Slack signing secrets, Azure variables, AI API keys</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Fortune 500 Companies Targeted in Azure Data Exfiltration Campaign
A threat actor claimed to have stolen millions of employee records from Fortune 500 companies' Azure cloud infrastructure, including McDonald's, TCS, Vodafone, and others. The data, obtained via compromised credentials from targeted infostealer campaigns, includes employee names, emails, IDs, and highly privileged account details, creating significant risk for social engineering and privilege escalation attacks.

<ul class="takeaways">
<li>McDonald&#x27;s: 1.7 million records; TCS: 800,000; Vodafone: 425,000</li>
<li>Data exfiltrated from Azure/Entra via leaked credentials</li>
<li>Exposed: employee names, emails, IDs, manager details, service accounts</li>
<li>Compromised data enables social engineering and privilege escalation attacks</li>
</ul>
