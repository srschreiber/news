### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Cisco Secure Email Gateway Vulnerability Exploited in the Wild
Unauthenticated attackers can write arbitrary files and execute commands with root privileges on Cisco Secure Email Gateway systems.

<ul class="takeaways">
<li>CVE-2026-76519 allows unauthenticated remote command execution as root (CVSS 9.8)</li>
<li>Requires File Reputation service enabled and Content Scanner Tools version earlier than 25.3.0.5525</li>
<li>Fixed in AsyncOS 15.5.5-014, 16.5.0-780, and Content Scanner Tools 25.3.0.5525 or later</li>
<li>Active exploitation discovered October 2026; AsyncOS 16.0 requires migration to fixed release</li>
<li>CVE-2026-76519 rated CVSS 9.8; zero-day actively exploited in the wild</li>
<li>Flaw in Advanced Malware Protection; unauthenticated attacker executes root commands via malicious email attachment</li>
<li>Affects SEG physical/virtual appliances and Panorama where File Reputation service enabled</li>
<li>CISA added to Known Exploited Vulnerabilities; federal agencies have Saturday remediation deadline</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Hackers deploy PEERSTITCH malware on FortiGate firewalls via Fortinet vulnerabilities
Attackers exploited Fortinet vulnerabilities to install PEERSTITCH, a stealthy ARM64 malware on FortiGate firewalls in a telecom organization breach. The memory-resident malware leaves no disk artifacts, opens no ports, and communicates through legitimate process traffic, enabling long-term access to intercept network data and compromise 500+ managed firewalls.

<ul class="takeaways">
<li>CVE-2024-47575 exploited against centralized FortiManager appliance for initial compromise</li>
<li>CVE-2025-61624 exploited via FortiOS auto-script path traversal to deploy PEERSTITCH malware</li>
<li>PEERSTITCH is memory-resident ARM64 malware leaving no persistent binary on disk</li>
<li>Attackers exfiltrated configurations and cryptographic material for 500+ managed firewalls</li>
<li>Intrusion tracked as cluster CL-STA-0954 (aka UNC5820)</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Hirudo Android RAT replaces banking apps with trojanized versions
Hirudo is a novel Android remote access trojan combining banking malware and full RAT capabilities, delivered via droppers embedded in seemingly legitimate shopping, adult video, and short drama apps. Hirudo detects specific banking apps, displays fake update prompts, replaces them with trojanized versions, and uses sophisticated hooking to blind signature verification and accessibility checks. Currently targets eight Indonesian banking apps with code suggesting potential expansion to China, India, Mexico, Morocco, and Thailand.

<ul class="takeaways">
<li>Hirudo targets 8 Indonesian banking apps; code hints at China, India, Mexico, Morocco, Thailand expansion</li>
<li>Delivered via droppers in shopping, adult video, short drama apps on social media</li>
<li>Trojanized replacement apps include hooking engine bypassing signature and Accessibility Services verification</li>
<li>Capabilities: steal credentials, remote device control, live camera views, SMS theft (90-day historical scan)</li>
</ul>
