### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Critical unpatched vulnerability in LMCache allows unauthenticated remote code execution
LMCache, an open-source LLM acceleration tool, contains a critical unpatched vulnerability (CVE-2026-105192, CVSS 9.8) allowing unauthenticated remote code execution. The flaw exists in multiprocess mode where the cache server unpacks ZeroMQ messages using Python pickle without authentication or type validation. Official Kubernetes examples expose the vulnerability remotely; processes run as root.

<ul class="takeaways">
<li>CVE-2026-105192, CVSS 9.8, unpatched critical vulnerability</li>
<li>Affects LMCache 0.3.9–0.5.5 and 0.5.6 release candidates</li>
<li>No patched version released as of Oct 7, 2026</li>
<li>Official Kubernetes example exposes multiprocess server to remote access</li>
<li>Cache process runs as root; exploited code executes with root privileges</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Attackers Hijack Top-Level Domains to Mint Unauthorized Security Certificates for Major Organizations
Attackers hijacked top-level domain registrations in Ghana, Sierra Leone, and American Samoa to compromise DNS records and issue fraudulent SSL certificates impersonating Google and other organizations. The attack allowed malicious redirects without triggering browser warnings, enabling potential data interception and phishing.

<ul class="takeaways">
<li>Compromised .gh, .sl, .as country-code domains to hijack DNS and issue false SSL certificates</li>
<li>Google and multiple organizations impersonated; scope of affected domains unclear</li>
<li>Fraudulent certificates redirected users without browser security warnings</li>
<li>Google detected attack and blocked certificates in Chrome; certification authorities faultless</li>
<li>Three ccTLD registries compromised: .gh (Ghana), .sl (Sierra Leone), .as (American Samoa)</li>
<li>12 unauthorized certificates issued Sept 22–27, 2026</li>
<li>Covered 7 domains: google.com.gh, google.sl, google.as, youtube variants</li>
<li>Let&#x27;s Encrypt issued 11, ZeroSSL issued 1 certificate</li>
<li>Attackers could impersonate Google/YouTube over encrypted connections</li>
</ul>
