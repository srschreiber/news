### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Windows 11 zero-day flaw allows lock screen bypass and code execution
Security researcher Chaotic Eclipse disclosed a Windows 11 zero-day vulnerability called FastUnlock on November 19, 2026 that exploits the Narrator accessibility feature to bypass the lock screen and execute code on locked machines. The exploit requires physical access and a Microsoft account, allowing code execution under a restricted user account even on fully encrypted systems with current security patches.

<ul class="takeaways">
<li>Vulnerability called FastUnlock; disclosed Nov 19, 2026</li>
<li>Exploits Narrator accessibility feature to bypass lock screen</li>
<li>Requires physical access and Microsoft account via lock screen recovery</li>
<li>Demonstrated breaching encrypted Windows 11 26H2 in ~5 minutes</li>
<li>Executes under restricted WSIAccount (not administrator)</li>
<li>Microsoft has not released patch; no confirmed real-world exploitation</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Ghostscript sandbox-escape vulnerability enables RCE via crafted file uploads
A patched use-after-free vulnerability (CVE-2026-125396) in Ghostscript allows crafted image and document files to escape sandbox protections and execute arbitrary commands on processing servers. The flaw affects common libraries used by WordPress, email clients, and print systems, with exploitation demonstrated across ten applications before the September 2026 fix.

<ul class="takeaways">
<li>Use-after-free in font-loading code disables -dSAFER sandbox checks</li>
<li>Affects Ghostscript versions before 10.08.0 (patched Sept 8, 2026)</li>
<li>Exploitable via disguised files (.png, .jpg, .pdf extensions)</li>
<li>Demonstrated exploitation in WordPress Core, Roundcube, print queues, and plugins</li>
<li>CVE score 8.5/10; no active exploitation reported at publication</li>
</ul>
