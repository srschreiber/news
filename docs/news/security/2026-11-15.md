### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Cursor Breach: Stolen Fireworks Key Trojanized Claude Extension
Hackers used a stolen Fireworks AI access key to compromise Anthropic's official Claude Code extension on Cursor's marketplace, affecting up to 5,000 users.

<ul class="takeaways">
<li>Malicious Claude Code extension v2.1.313 affected up to 5,000 users via Cursor marketplace</li>
<li>Malware: 66-line loader installing persistent SSH backdoor with attacker&#x27;s key (&quot;svc-telemetry&quot;)</li>
<li>Transmitted host reconnaissance (IP, hostname, OS, CPU, Git email) unencrypted to 134.209.82.225:8099</li>
<li>Installed platform-specific persistence: scheduled task (Windows), crontab (Linux), LaunchAgent (macOS)</li>
<li>Attacker obtained Fireworks AI credentials; method remains unclear; marketplace temporarily shut down</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Attackers target 60,000 GitHub repositories in credential theft campaign
The wfx-loot campaign began November 10, 2026, using approximately 4,800 hijacked accounts to target 61,764 GitHub repositories and steal developer credentials. Malware was deployed in repositories where permissions allowed, with evidence showing credential-stealing code ran in over 1,800 repositories and 8,093 received malicious commits.

<ul class="takeaways">
<li>Campaign began November 10, 2026, used ~4,800 hijacked accounts</li>
<li>Targeted 61,764 GitHub repositories with probe pull requests</li>
<li>Malware ran in 1,800+ repositories; 8,093 received malicious commits</li>
<li>Stole GitHub tokens, repository secrets, cloud credentials, and AI service keys</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Italy Fines Meta €805 Million for Facebook Android Gallery Access Without Consent
Italy's data protection authority fined Meta €805 million on November 14 for a Facebook Android feature that accessed users' phone galleries without explicit consent. The feature was enabled by default since 2023, and Meta must within 60 days request separate consent, disable the feature by default, and report on remediation efforts.

<ul class="takeaways">
<li>Fine: €805 million (0.47% of Meta&#x27;s global revenue) issued November 14, 2026</li>
<li>Feature accessed phone galleries without explicit user consent since 2023</li>
<li>Feature enabled by default; Meta must disable by default within 60 days</li>
<li>Meta must request separate, specific consent within 60 days or feature cannot be enabled</li>
</ul>
