### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Critical Orkes Conductor Remote Code Execution Vulnerability Exploited
CVE-2026-58138, a critical unauthenticated remote code execution flaw in Orkes Conductor, is being actively exploited in the wild. The vulnerability allows attackers to inject malicious code via workflow API endpoints and execute arbitrary system commands with root privileges.

<ul class="takeaways">

<li>Proof-of-concept published early August; in-the-wild exploitation confirmed August 21</li>
<li>Fortinet blocked ~1,300 exploitation attempts September 8–9</li>
<li>GraalVM HostAccess.ALL configuration disables sandboxing</li>
</ul>
