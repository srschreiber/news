### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> F5 patches critical BIG-IP zero-day vulnerability in OAuth servers
F5 released patches on September 22, 2026 for CVE-2026-94127, a critical zero-day vulnerability (CVSS 9.8/10) in BIG-IP Access Policy Manager allowing unauthenticated remote code execution via heap-based buffer overflow. CISA added the flaw to its Known Exploited Vulnerabilities catalog.

<ul class="takeaways">
<li>CVE-2026-94127 rated 9.8/10 CVSS v3.1, 9.3/10 CVSS v4.0</li>
<li>Affects BIG-IP 21.1.0, 17.5.0–17.5.1, 17.1.0–17.1.3 when APM functions as OAuth server</li>
<li>CISA issued directive: federal agencies must patch by September 25</li>
<li>Limiting management interface access does not prevent exploitation</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Critical Next.js ImageResponse Vulnerability Enables Server Code Execution via SVG Injection

<ul class="takeaways">

<li>Fixed September 22 in version 16.3.6</li>
<li>Flaw stems from improper escaping in Satori&#x27;s SVG output</li>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> First Autonomous AI Command-and-Control Malware Uses Multi-Model Voting System
Security researchers discovered CLOSEQUORUM, the first autonomous AI command-and-control malware that uses four commercial LLMs voting on attack actions instead of receiving human commands. The malware focuses on stealing credentials and cryptocurrency, with decisions logged to Discord via encrypted webhooks.

<ul class="takeaways">
<li>Four LLMs vote on actions: DeepSeek, Qwen, Mistral, Gemini</li>
<li>Actions include credential stealing, code injection, persistence</li>
<li>Stolen data encrypted with AES-256-GCM before transmission to Discord</li>
<li>Binary analyzed contained placeholder API keys suggesting malware-as-a-service model</li>
<li>No confirmed in-the-wild deployment detected</li>
</ul>
