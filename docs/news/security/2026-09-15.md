### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Cisco Secure Email Gateway zero-day enables root command execution under active attack
Cisco disclosed a critical zero-day vulnerability (CVE-2026-76461, CVSS 9.8) in Secure Email Gateway that allows unauthenticated attackers to execute arbitrary commands with root privileges via malicious email messages. The flaw is actively being exploited in the wild and affects both physical and virtual devices; patching is required as no workarounds exist.

<ul class="takeaways">
<li>CVE-2026-76461, CVSS 9.8 severity</li>
<li>Unauthenticated remote root command execution via email</li>
<li>Actively exploited in the wild</li>
<li>Fixed versions: AsyncOS 15.5.5-0141, 16.0.4-302, 16.5.0-780</li>
<li>CISA requires Federal agencies to patch by September 17, 2026</li>
<li>CVE-2026-76461 (CVSS 9.8): critical vulnerability in AsyncOS email handling</li>
<li>Unauthenticated remote code execution via malicious email</li>
<li>Active exploitation detected September 2026; cloud customers targeted and upgraded</li>
<li>No workarounds; patching to AsyncOS 16.5.0-780 required mitigation</li>
<li>Attackers with root access can tamper with logs to cover tracks</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Critical LiteSpeed Web Server Vulnerability Allows Root Access on Shared Hosting
LiteSpeed Web Server Enterprise contains a critical vulnerability allowing low-privileged website users to gain root access on shared hosting servers by bypassing file system isolation controls including CageFS. Version 6.3.7, released September 11, 2026, addresses the flaw; manual installation is recommended over auto-update.

<ul class="takeaways">
<li>Affects versions before 6.3.7 released September 11, 2026</li>
<li>Low-privileged user to root privilege escalation</li>
<li>Bypasses CageFS file system isolation</li>
<li>Third root-access vulnerability in LiteSpeed since May 2026</li>
<li>OpenLiteSpeed (open-source) unaffected as of September 15</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Chinese Hackers Exploit Chrome-Windows Zero-Day Chain to Deploy GRIMWEDGE Backdoor
Chinese threat actor UTA0560 exploited a three-zero-day chain in Chrome and Windows to deliver the GRIMWEDGE JavaScript backdoor targeting NGOs. The attack chain included Chrome sandbox escape, Windows privilege escalation, and an XSS vulnerability, delivering backdoor malware capable of reconnaissance, file management, and command execution.

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> BambooToken Malware Exploits MQTT to Control Windows and Linux Systems
Researchers at Lumen Black Lotus Labs disclosed BambooToken, an emerging multi-platform malware family active since at least February 2023 that uses the MQTT protocol for command-and-control of Windows and Linux systems. Initial access is achieved through DLL sideloading of Tendyron's OnKey PKI security token software; most samples originate from Chinese IP space and target organizations across Asia and South America.

<ul class="takeaways">
<li>Malware: BambooToken, active since Feb 2023, discovered on VirusTotal early 2026</li>
<li>Platforms: Windows and Linux; C2 via MQTT protocol</li>
<li>Initial access: DLL sideloading of Tendyron OnKey software (PKI USB token)</li>
<li>Targets: organizations in Asia and South America</li>
<li>Most samples from Chinese IP space; latest activity July 2026</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> KREMLIN Banking Malware Hijacks Chrome and Edge to Steal Credentials
Elastic Security Labs disclosed KREMLIN, a Brazilian banking malware toolkit active since May 2025 that hijacks Chrome and Edge browsers to steal credentials and session tokens. The multi-stage attack uses JavaScript loaders, custom C++ installers, and malicious browser extensions impersonating a dozen Brazilian banks and exploits blockchain-based Ethereum smart contracts as dead drop resolvers for dynamic C2 updates.

<ul class="takeaways">
<li>Malware: KREMLIN (REF9334), active since May 2025</li>
<li>Targets: Brazilian banks via fake banking/invoice/company documents in Portuguese</li>
<li>Browser extensions targeted: Chrome and Edge, extension ID ndpbidppejfanjbhfgjlohfanbfbklff</li>
<li>Uses Ethereum smart contracts as dead drop C2 resolvers for endpoint updates</li>
<li>Sandbox/VM evasion; DLL sideloading via SentinelOne binary; credential/token theft</li>
</ul>

U.S., U.K., and Netherlands cybersecurity agencies identified Windows malware attributed to Iran's Ministry of Intelligence and Security (MOIS) used to surveil dissidents, journalists, and activists globally via Telegram. The malware (HEAVYGRAM/CHOSEN BRICK) can copy emails and messages, take screenshots, and record audio; confirmed targeting spans the U.S., U.K., and Netherlands since at least 2025, with the campaign dating to autumn 2023.

<ul class="takeaways">
<li>Malware: HEAVYGRAM (FBI) / CHOSEN BRICK (UK NCSC), attributed to Iran MOIS</li>
<li>Campaign active since autumn 2023; confirmed targeting since 2025</li>
<li>Targets: dissidents, journalists, activists in U.S., U.K., Netherlands</li>
<li>Telegram-controlled; capabilities: email/message copy, screenshots, audio recording</li>
<li>Attack vectors: social engineering, fake apps (Pictory, KeePass, Telegram, RunwayML, Norton, Adobe, MRI scans)</li>
</ul>
