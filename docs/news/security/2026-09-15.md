### <span class="imp imp-high" title="Importance 8.5/10" aria-label="Importance 8.5 of 10">8.5</span> Cisco Secure Email Gateway zero-day enables root command execution under active attack
Cisco disclosed a critical zero-day vulnerability (CVE-2026-76461, CVSS 9.8) in Secure Email Gateway that allows unauthenticated attackers to execute arbitrary commands with root privileges via malicious email messages. The flaw is actively being exploited in the wild and affects both physical and virtual devices; patching is required as no workarounds exist.

<ul class="takeaways">
<li>CVE-2026-76461, CVSS 9.8 severity</li>
<li>Unauthenticated remote root command execution via email</li>
<li>Actively exploited in the wild</li>
<li>Fixed versions: AsyncOS 15.5.5-0141, 16.0.4-302, 16.5.0-780</li>
<li>CISA requires Federal agencies to patch by September 17, 2026</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Critical LiteSpeed Web Server Vulnerability Allows Root Access on Shared Hosting
LiteSpeed Web Server Enterprise contains a critical vulnerability allowing low-privileged website users to gain root access on shared hosting servers by bypassing file system isolation controls including CageFS. Version 6.3.7, released September 11, 2026, addresses the flaw; manual installation is recommended over auto-update.

<ul class="takeaways">
<li>Affects versions before 6.3.7 released September 11, 2026</li>
<li>Low-privileged user to root privilege escalation</li>
<li>Bypasses CageFS file system isolation</li>
<li>Third root-access vulnerability in LiteSpeed since May 2026</li>
<li>OpenLiteSpeed (open-source) unaffected as of September 15</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Chinese Hackers Exploit Chrome-Windows Zero-Day Chain to Deploy GRIMWEDGE Backdoor
Chinese threat actor UTA0560 exploited a three-zero-day chain in Chrome and Windows to deliver the GRIMWEDGE JavaScript backdoor targeting NGOs. The attack chain included Chrome sandbox escape, Windows privilege escalation, and an XSS vulnerability, delivering backdoor malware capable of reconnaissance, file management, and command execution.

<ul class="takeaways">
<li>Three zero-day vulnerabilities: CVE-2026-85046, CVE-2026-87491, CVE-2026-85880</li>
<li>GRIMWEDGE JavaScript backdoor with host reconnaissance and file management</li>
<li>Spear-phishing campaign September 1, 2026 targeting NGOs</li>
<li>Three-stage exploit chain called BlueMoon</li>
<li>Persistence via MSI installer with obfuscated JavaScript</li>
</ul>
