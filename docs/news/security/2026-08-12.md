### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Windows Zero-Day Vulnerability Exploited by North Korean Hackers
North Korean attackers exploited a Windows zero-day flaw (CVE-2026-68820) in the Ancillary Function Driver to deploy the ForestTiger backdoor and gain full system control, targeting aerospace and aviation organizations across Europe and India via fake job recruitment lures. Microsoft patched the vulnerability on August 11, 2026.

<ul class="takeaways">
<li>CVE-2026-68820: use-after-free in afd.sys enabling privilege escalation to System</li>
<li>Lazarus Group campaign active since early 2026, primarily targeting defense sector</li>
<li>Infection chains: DLL sideloading → Mistpen downloader → zero-day → ForestTiger; also trojanized SecurityPDF → Troy backdoor</li>
<li>Troy implant supports 17 operator commands including file ops, exfiltration, shell access</li>
<li>Microsoft patched August 11, 2026; CISA ordered federal agencies to patch within two weeks</li>
</ul>

### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> Malicious LiteLLM Releases From Trivy Hack Exposed 2,100+ Organizations
Two poisoned versions of the LiteLLM Python package sat on PyPI for 40 minutes in March, carrying credential-stealing malware that potentially exposed over 2,100 organizations' cloud keys, SSH credentials, and database passwords. The packages were inserted during a Trivy security tool compromise and communicated stolen data to an attacker-controlled domain.

<ul class="takeaways">
<li>Malicious versions 1.82.7 and 1.82.8 deployed March 24, 10:39–11:19 UTC</li>
<li>Harvested cloud keys, SSH keys, Kubernetes tokens, database passwords, environment variables</li>
<li>2,500+ organizations&#x27; signals found in captured CI runner data (not confirmed victims)</li>
<li>Included victims like NVIDIA, Cisco, Deloitte, Volkswagen, FedEx, Siemens, X Corp</li>
<li>FBI advisory FLASH-20260702-01 warned credentials likely to be weaponized; rotate secrets immediately</li>
</ul>
