### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Critical Ruby on Rails vulnerability KindaRails2Shell enables arbitrary file read and remote code execution
A critical Ruby on Rails vulnerability (CVE-2026-66066, CVSS 9.5) named KindaRails2Shell enables arbitrary file read and remote code execution in applications using libvips for image processing. Attackers exploit differing file-type detection methods to craft files that trigger HDF5's External File List feature, reading server files and extracting credentials. Threat actors began exploiting the flaw one month after patches were released in late July.

<ul class="takeaways">
<li>CVE-2026-66066 with CVSS score 9.5 (critical)</li>
<li>Affects Rails apps using libvips for Active Storage with untrusted image uploads</li>
<li>Enables arbitrary file read and remote code execution via HDF5 External File List</li>
<li>Unauthenticated attackers can extract credential databases and storage keys</li>
<li>Exploitation began ~one month after patches released in late July</li>
</ul>

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> China-Linked Fire Ant Cyber Espionage Group Compromises Cisco Routers and Authentication Systems
China-nexus cyber espionage group Fire Ant expanded operations to compromise Cisco IOS XR routers, TACACS servers, and Linux management hosts for credential theft and security log manipulation. The group deployed custom malware including tools to suppress logging, filter security alerts, and capture network traffic. Activity was limited to scanning vulnerable environments; no confirmed compromise of critical infrastructure targets.

<ul class="takeaways">
<li>Fire Ant targeted Cisco IOS XR routers, TACACS servers, Linux management hosts</li>
<li>Deployed purpose-built malware including TacTap credential-collection tool</li>
<li>Custom IOS XR malware filtered logs to show only &quot;Health&quot; strings, hid tunnel configuration</li>
<li>Used routers to capture network traffic (PCAPs) and upload to external FTP servers</li>
<li>Strong overlap with UNC3886 (China-nexus group targeting virtualization platforms)</li>
<li>Activity limited to scanning; no confirmed critical infrastructure compromise</li>
</ul>
