### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Hackers Actively Exploiting GeoServer Zero-Day Vulnerability
Hackers began exploiting an unpatched zero-day SQL injection vulnerability in GeoServer within hours of public disclosure on August 14, 2026, enabling remote code execution through the jsonArrayContains filter expression. ### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> AmnesiaStealer macOS Malware Steals Data and Controls Browser Sessions
AmnesiaStealer is a Rust-based macOS infostealer distributed via counterfeit GitHub pages in ClickFix attacks that harvests credentials, keychain data, and browser information while enabling attacker-controlled browser session hijacking. The malware overwrites encryption keys in the login keychain to make previously saved passwords and cookies unrecoverable.

<ul class="takeaways">
<li>Distributed through counterfeit GitHub pages installed via pasted Terminal commands</li>
<li>Targets six Chromium-based browsers including Chrome, Brave, Arc, and Edge</li>
<li>Overwrites per-browser Safe Storage key to render saved passwords and cookies unrecoverable</li>
<li>Includes TCC framework bypasses for Safari cookies; installs LaunchDaemon for persistence</li>
<li>Remote_stream command enables attacker control of cloned browser profile</li>
</ul>
