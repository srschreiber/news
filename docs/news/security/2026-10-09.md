### <span class="imp imp-high" title="Importance 7.6/10" aria-label="Importance 7.6 of 10">7.6</span> Midnight Mimosa Malware Pre-Installed on Budget Android Devices in 150+ Countries
Midnight Mimosa is a malware campaign discovered and analyzed by Bitdefender that comes pre-installed in the firmware of low-cost Android devices built on MediaTek platforms. The malware is a persistent, pre-installed firmware system app that cannot be removed through normal uninstall procedures and runs with system-level privileges. It operates as a silent installer capable of installing and removing apps, granting permissions, and loading arbitrary code supplied remotely by operators via command-and-control (C2) servers. The campaign focuses on ad fraud, automated click fraud, and recruitment of devices into large botnets that can be rented to other actors. Over the last two years, Bitdefender observed thousands of unique affected devices across more than 150 countries, with Mexico and France leading in distribution, followed by Italy, the US, Germany, Brazil, and Spain. Western Europe and the Americas are noted as regions with higher concentrations of affected devices. Bitdefender also identified 13 apps on Google Play with separate signing certificates under two developer accounts containing the same Midnight Mimosa ad-fraud code. The malware gives operators the ability to customize each device according to their needs.

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> Microsoft to End Security Updates for Unsupported Windows Versions After Certificate Rotation
Microsoft announced that devices running unsupported versions of Windows will lose access to Windows Update services after security certificate expiration deadlines in 2027. The Secure Boot certificates, originally created in 2011 during Windows 8 development, expire in May and June 2027. Microsoft is distributing replacement certificates through regular security updates. Supported Windows versions with current monthly security updates will not require additional action. Specific deadlines: Windows 11 25H2 and later already have the necessary certificates; Windows 11 24H2 and Windows Server 2025 must install the September 2025 security update or later by June 19, 2027; other supported Windows 11 versions and Windows Server 2022 must install the July 2026 security update or later by June 19, 2027; supported Windows 10 versions must install the July 2026 security update or later by June 19, 2027; Windows 10 Enterprise 2019 LTSC, Windows Server 2019, and Windows Server 2016 must install the July 2026 security update or later by May 17, 2027. Devices running unsupported Windows versions must upgrade to a supported release to maintain Windows Update access. Devices that do not update will continue to function but enter a degraded security state and may be unable to install new boot-level security mitigations, eventually fail to install or boot newer operating systems, or be unable to load future firmware and hardware updates.

### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> GoBalance vulnerability allows Tor .onion address hijacking via key recovery
GoBalance, a Tor load-balancing tool written in Go and distributed with EndGame (a toolkit for keeping dark-web sites online during denial-of-service attacks), contains a vulnerability that allows attackers to recover the private keys controlling .onion addresses using only publicly available information. The flaw was disclosed by Searchlight Cyber on October 8, 2026. The vulnerability exists in GoBalance's key-signing implementation: Tor private keys are 64 bytes long, but GoBalance passed only the first 32 bytes to the signer and discarded the remaining 32 bytes—the portion that keeps each signature's secret value hidden. Without this discarded half, the secret value becomes a fixed number that anyone can compute from a single published descriptor, allowing recovery of the site's long-term master key without server access. Because the recovered key is the site's master key rather than a short-lived one, it can be used to sign valid records for the address indefinitely into the future. The vulnerability affects only GoBalance sites whose master keys are stored in Tor's native key format; sites using GoBalance's setup tool, which writes keys in a safer format, are not at risk. The original Onionbalance and Tor itself are unaffected. The flaw was publicly revealed through the takeover of Dread, one of the dark web's largest forums, between October 5 and 7, 2026: both of Dread's .onion addresses were compromised and redirected to a rival site called Conclave. Dread's operators initially attributed the first takeover to an accidental private key upload but later acknowledged the second address takeover as evidence of the GoBalance vulnerability being exploited. Dread moved to a new address and instructed users to change passwords; the operators confirmed Dread's servers were not breached. HugBunter stated that several dark-web markets also had their addresses taken over via the vulnerability, though specific names were not disclosed.
