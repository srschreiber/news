### Adobe BPO Breach Exposes 13 Million Records via Phished Support Agent
🔥🔥🔥🔥◯ A threat actor calling itself "Mr. Raccoon" claims to have breached Adobe through an Indian business-process-outsourcing contractor, exfiltrating 13 million Adobe customer records and unpublished vulnerability reports from Adobe's HackerOne bug bounty program using access gained from one phished support agent. The attacker reportedly deployed a remote access tool on a BPO employee's machine via a phishing email, then expanded access by targeting the employee's manager through a second phishing attempt. The exposed data spans customer names, emails, and account IDs, plus roughly 15,000 employee records and internal documents; the unpatched HackerOne submissions are considered the most dangerous element since they become a roadmap for exploitation: step-by-step instructions for compromising Adobe software. Support agents were reportedly able to export all tickets in one request from an agent, pointing to a bulk-export control gap rather than a policy failure. Adobe has not confirmed the incident, and analysts note third-party BPO access is a recurring 2026 breach pattern across multiple companies.
