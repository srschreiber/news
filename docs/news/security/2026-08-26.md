### <span class="imp imp-high" title="Importance 7.5/10" aria-label="Importance 7.5 of 10">7.5</span> CISA alerts of actively exploited Gitea remote code execution vulnerability
CISA added CVE-2026-60004, a remote code execution flaw in Gitea, to its Known Exploited Vulnerabilities catalog after detecting active exploitation in the wild. The vulnerability, patched in Gitea 1.27.1 in late July, allows attackers with repository write access to inject malicious code and execute shell commands. Federal agencies must patch by August 28, 2026.
