### <span class="imp imp-high" title="Importance 7/10" aria-label="Importance 7 of 10">7</span> SLEEPWALKER backdoor malware awaits crafted packet trigger, executes custom bytecode
Researchers documented SLEEPWALKER, a Windows backdoor malware that remains dormant until activated by a crafted network packet, then executes commands in a proprietary 23-instruction bytecode language. The unsigned 64-bit DLL side-loads into ESET Management Agent, masquerades as Microsoft's dpapi.dll, and contains no hardcoded domains or outbound connections.

<ul class="takeaways">
<li>59,904-byte unsigned 64-bit Windows DLL</li>
<li>Executes proprietary 23-instruction bytecode language</li>
<li>Side-loads into ERAAgent.exe, impersonates dpapi.dll with seven exported functions</li>
<li>AES-256-CCM encryption; no hardcoded domains, IPs, or URLs</li>
<li>Persists via Windows DLL search order only; post-compromise implant, not entry point</li>
<li>Initial compromise method unknown; attribution and victims undetermined</li>
</ul>
