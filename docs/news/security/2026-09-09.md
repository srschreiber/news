### <span class="imp imp-high" title="Importance 9/10" aria-label="Importance 9 of 10">9</span> SAP Patches CVSS 10.0 Kernel Flaw Enabling Unauthenticated Remote Code Execution
SAP patched CVE-2026-44756, a CVSS 10.0 maximum-severity vulnerability in SAP Extended Passport Processing that allows unauthenticated remote code execution. A second critical flaw (CVE-2026-58240, CVSS 9.8) was also patched, both enabling attackers to execute arbitrary commands and extract sensitive data without credentials.

<ul class="takeaways">
<li>CVE-2026-44756: CVSS 10.0, unauthenticated remote code execution via malformed EPP headers</li>
<li>CVE-2026-58240: CVSS 9.8, missing authentication in NetWeaver Message Server</li>
<li>Attackers can read SAP secure store, extract database credentials, and access session data</li>
<li>Flaws reachable through internet-facing protocols without pre-existing authentication</li>
</ul>
