### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> PAN-OS Firewall Management Interfaces Targeted via PHP Vulnerabilities
Attackers exploited CVE-2026-109618 and CVE-2026-109619 PHP vulnerabilities in internet-exposed Palo Alto Networks firewall management interfaces, compromising 25 systems across the U.S., Japan, Taiwan, and South Korea. The flaws allow unauthenticated remote code execution; attackers obtained PAN-OS firmware, decrypted it, and built memory profiles for nine software versions to chain exploits with Linux kernel flaws.

<ul class="takeaways">
<li>CVE-2026-109618 and CVE-2026-109619: unauthenticated RCE in PAN-OS web server</li>
<li>25 systems compromised (24 firewalls, 1 management server) in U.S., Japan, Taiwan, South Korea</li>
<li>Details leaked October 20; PHP emergency patch October 21</li>
<li>Attackers obtained and decrypted PAN-OS firmware, extracted PHP libraries, built memory profiles for 9 versions</li>
<li>Chained with Fragnesia (CVE-2026-46300) Linux kernel flaw to gain root access</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> F5 patches critical NGINX2Root vulnerabilities as exploits go public
F5 released patches on November 19, 2026 for five critical NGINX2Root vulnerabilities (CVSS 9.2 each) allowing remote unauthenticated code execution, as public proof-of-concept exploits became available. The vulnerabilities affect NGINX since version 1.9.5 (2015); code execution requires ASLR disabled, but researchers demonstrated both CVE-2026-123007 and CVE-2026-123633 can bypass ASLR themselves.

<ul class="takeaways">
<li>Five critical NGINX2Root flaws (CVE-2026-113425, 121810, 123007, 123633, 123634); CVSS 9.2 each</li>
<li>Affect NGINX 1.9.5 (2015) and newer (HTTP/2, HTTP/3, mail proxy, proxy servers)</li>
<li>Remote unauthenticated RCE; Rapid7 published PoC for CVE-2026-123007</li>
<li>CVE-2026-123007 and CVE-2026-123633 can bypass ASLR; CVE-2026-123007 causes buffer overflow; CVE-2026-123633 triggers use-after-free</li>
<li>Code execution runs with nginx worker privileges</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Java4Shell exploitation attempts begin as vendors issue security advisories
Java4Shell (CVE-2026-114938), a memory corruption flaw in OpenJDK 17.0.6+, enables unauthenticated remote code execution against Jira, Confluence, Jenkins, and other enterprise applications. Active probing began immediately after disclosure on November 17, 2026; GreyNoise recorded over 150 attack attempts as of early November 19, though no successful intrusions have been reported on its sensors.

<ul class="takeaways">
<li>CVE-2026-114938 (Java4Shell): memory corruption in OpenJDK 17.0.6+</li>
<li>Requires x86-64 processor with AVX-512 VBMI (newer Intel/AMD); ARM unaffected</li>
<li>Unauthenticated RCE against Jira, Confluence, Jenkins, Keycloak (default configs)</li>
<li>Over 150 attack attempts recorded by GreyNoise as of early Nov 19; no confirmed successful intrusions</li>
<li>Cisco, Elastic, Red Hat, Siemens issued impact advisories</li>
</ul>

### <span class="imp imp-high" title="Importance 8/10" aria-label="Importance 8 of 10">8</span> Ruby releases patches for 7 regex and string flaws, 5 with proof-of-concept RCE
Ruby released patches for seven memory-safety vulnerabilities in regex and string case-conversion code (versions 4.0.10, 3.4.13, 3.3.14). Five vulnerabilities have working proof-of-concept RCE exploits; three are critical, three high, one moderate. Risk depends on whether applications build regexes or perform case conversion on untrusted input.

<ul class="takeaways">
<li>Seven vulnerabilities fixed (3 critical, 3 high, 1 moderate)</li>
<li>Five have proof-of-concept RCE exploits</li>
<li>Critical: GHSA-34m4-m9fh-gqp5 (one-byte heap overflow, case conversion), GHSA-7x2q-68qv-6p8x (double free in regex), GHSA-3p8q-wmhx-vm2w (heap overflow in regex compilation)</li>
<li>High: GHSA-87fm-7w84-j2px (case conversion 4+ GiB), GHSA-7whj-cfh7-xgm4 (Regexp#to_s), GHSA-wpqw-5qxg-m68r (out-of-bounds read)</li>
<li>No attacks reported; risk depends on untrusted input handling</li>
</ul>
