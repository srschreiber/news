<div><a href="news/security/2026-10-09/#gobalance-vulnerability-allows-tor-onion-address-hijacking-via-key-recovery">GoBalance vulnerability allows Tor .onion address hijacking via key recovery</a>
<p>GoBalance, a Tor load-balancing tool written in Go and distributed with EndGame (a toolkit for keeping dark-web sites online during denial-of-service attacks), contains a vulnerability that allows attackers to recover the private keys controlling .onion addresses using only publicly available information. The flaw was disclosed by Searchlight Cyber on October 8, 2026. The vulnerability exists in GoBalance&#x27;s key-signing implementation: Tor private keys are 64 bytes long, but GoBalance passed only the first 32 bytes to the signer and discarded the remaining 32 bytes—the portion that keeps each signature&#x27;s secret value hidden. Without this discarded half, the secret value becomes a fixed number that anyone can compute from a single published descriptor, allowing recovery of the site&#x27;s long-term master key without server access. Because the recovered key is the site&#x27;s master key rather than a short-lived one, it can be used to sign valid records for the address indefinitely into the future. The vulnerability affects only GoBalance sites whose master keys are stored in Tor&#x27;s native key format; sites using GoBalance&#x27;s setup tool, which writes keys in a safer format, are not at risk. The original Onionbalance and Tor itself are unaffected. The flaw was publicly revealed through the takeover of Dread, one of the dark web&#x27;s largest forums, between October 5 and 7, 2026: both of Dread&#x27;s .onion addresses were compromised and redirected to a rival site called Conclave. Dread&#x27;s operators initially attributed the first takeover to an accidental private key upload but later acknowledged the second address takeover as evidence of the GoBalance vulnerability being exploited. Dread moved to a new address and instructed users to change passwords; the operators confirmed Dread&#x27;s servers were not breached. HugBunter stated that several dark-web markets also had their addresses taken over via the vulnerability, though specific names were not disclosed.</p>
